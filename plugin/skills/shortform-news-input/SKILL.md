# shortform-news-input

기사 기반 위임 제작에서는 짝 스킬의 [표현 선택 권한](../shortform-news-pipeline/reference/creative-authority.md)을 따른다. 자료와 원고를 왕복하고 적합한 자료·음성·도해를 선택할 수 있다. 한 제작자가 전체 설명을 책임지며, input/output이라는 이름 때문에 제작자를 둘로 나누지 않는다.

1. 원문·수집 자료는 그대로 보존하고 각 주장과 자료의 역할·출처·사용 근거를 연결한다.
2. 낭독 원고와 화면 표기를 구분하고 실제 음성·어절 시간을 만든다. 문장 수나 이전 편의 컷을 설명 구조로 강제하지 않는다.
3. 음성 뒤에도 원고를 수정할 수 있다. 관리 중인 편에서는 [작업 상태·재개](../shortform-news-pipeline/reference/production-state.md)의 begin/finish로 입력 버전과 실제 결과를 연결한다.
4. 위임된 초안·보이스·자료·세부 연출을 반복 승인받지 않는다. 이번 사용자 범위와 사실·출처 근거를 지킨다.
