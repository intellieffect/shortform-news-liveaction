# 자료 선택과 수집

기사 위임 제작에서는 제작자가 설명·원고와 자료를 함께 판단한다. 한 개념을 설명하는 데 실제 영상·사진·새 도해·생성 표현 중 무엇이 적합한지 선택하고 필요하면 교체한다. 참고할 기존 부품이나 자료가 있다는 이유로 선택을 고정하지 않는다.

1. 필요한 대상·관계·변화와 전체 이야기에서 맡을 일을 정한다. 검색어를 문장의 명사로만 제한하지 않는다. 후보의 실제 내용·움직임·세로 크롭·모바일 정보량을 확인한다.
2. 자료가 실제 증거인지, 개념 설명인지, 비유·분위기인지 구분하고 원고의 주장과 연결한다. 생성한 표현을 특정 관측·실존 대상의 실제 모습으로 제시하지 않는다.
3. 원본은 그대로 보존하고 URL·크레딧 원문·자산별 사용 근거·가공/생성 여부를 기록한다. 기관 이름만으로 모든 파일의 사용 조건을 추정하지 않는다. 필요한 출처 표기는 시청 흐름 안에서 읽히게 설계한다.
4. 자료 수집과 생성 순서는 이번 설명에 맞게 결정한다. 과거의 수집판/생성판 분리, 모든 실사 후보 소진, 비트별 생성 개수, 고정 시트 승인을 기사 위임 제작의 선행 조건으로 삼지 않는다. 비용·자료 권한은 현재 사용자 위임 범위를 따른다.
5. BGM·효과음이 위임됐으면 제작자가 선택하고 실제 발화·장면에 맞춰 믹스한다. 최종 음향은 [실물 검수](../../shortform-news-pipeline/reference/review-loop.md)에 따라 청취·측정한다.

## 소싱 담당에게 넘길 맥락

종류별 담당 경로와 원본 저장 경로를 함께 배정한다. [실행 도구와 병렬 작업](../../shortform-news-pipeline/reference/execution-efficiency.md)의 manifest 다운로드를 사용하고, 후보표에는 실제 파일과 타임코드 미리보기 경로를 연결한다. 제작자는 담당자별 결과를 선택·통합하고, 공용 정본을 여러 담당자가 동시에 수정하지 않게 한다.

기존 `asset_gaps.json`과 작업 요청에 **현재 제작 모드, 영상 전체의 질문과 흐름, 이 자료로 시청자가 이해하거나 느껴야 할 것, 지켜야 할 사실, 바꿔도 되는 표현**을 함께 준다. 문서나 스키마를 하나 더 만들 필요는 없다. `kw`는 검색 실마리이며 editorial 경로의 검색 범위를 결정하지 않는다.

특정 사건·장소의 관측 증거가 필요한 요청과, 그 현상을 이해시킬 맥락·과정·규모·정서가 필요한 요청을 구별한다. 다른 대상의 자료를 특정 관측으로 소개하지 않으면서도, 설명에 쓸 수 있는 자료의 범위는 열어둔다. 모든 역할을 의무적으로 채우지 않는다. 음악 요청에도 전체 정서 변화와 내레이션의 자리를 전달한다.

회신에서 제작자는 후보 자체뿐 아니라 현재 검색 범위가 적절했는지를 본다. 후보가 없거나 화면 효과가 약하면 그 자리를 도해로 채우기 전에 구간의 목적과 자료·원고 구성을 함께 재검토한다. 필요한 후보를 충분히 찾았거나 접근·권리 한계가 분명하면 근거를 남기고 다음 선택으로 진행한다. 고정 사이트 소진이나 목표 제작 시간이 표현 선택권을 대신하지 않는다.

수집 도구는 현재 세션의 실제 사용 가능 여부를 확인하고 저장소의 검색·브라우저 지침을 따른다. 지정된 소싱 에이전트 호출 시점과 권한은 [agents.md](../../shortform-news-pipeline/reference/agents.md)를 따른다. 검수자는 실제 적합성과 오인 가능성을 판단한다.

제공 대본을 그대로 구현하는 편의 기존 회수 순서·시트·생성판·도구별 수집 세부와 사례는 [script-faithful-sourcing.md](script-faithful-sourcing.md)를 읽는다. 그 문서의 사람 선택·단계 고정 조건을 기사 위임 경로에 가져오지 않는다.
