# 공용 음원 폴더

여러 편에서 다시 쓰는 배경음악은 제작 저장소의 `library/music/`에 둔다. 목록 `catalog.json`은 git이 추적하고 음원 파일(`files/`)은 추적하지 않는다. 사용자가 폴더에 파일을 직접 넣게 하지 않는다 — 명령이 출처·해시·추가일을 자동 기록한다. 경로는 제작 저장소 기준이다.

## 요청 → 명령

| 사용자 요청 예 | 할 일 |
|---|---|
| "<음원 파일 또는 주소> 이 음원 공용 음원 폴더에 넣어줘" | `npm run music -- add "<URL 또는 파일 경로>"` — 사용자가 라이선스·사용 범위를 **스스로** 적었을 때만 `--license "<원문>"`·`--usage "<원문>"`를 붙인다 |
| "공용 폴더 보유 음원 목록 보여줘" | `npm run music -- list` — 출력 표를 그대로 보여 준다 |
| "공용 음원 폴더의 <파일 이름> 이 편 배경음악으로 써줘" | `npm run music -- use "<곡 id 또는 파일 이름>" <편 id>` → `npm run sync -- news/<편 id>` → 믹스 청취 |
| 파일이 빠졌는지 확인 | `npm run music -- check` |

- **라이선스·사용 범위·크레딧 문구를 묻지 않는다.** 공용 폴더 음원의 권리 확인은 음원을 넣는 쪽(한겨레)이 맡는다. 사용자가 스스로 적어 준 경우에만 그 문장을 **그대로** `--license`·`--usage`로 옮긴다 — 추측해 채우지 않는다. 미기재는 오류가 아니다.
- **끝 크레딧 "음악" 줄 = 공용 폴더의 파일 이름(확장자 제외).** 크레딧 문구를 따로 받지 않는다. 표기를 바꾸려면 사용자가 원하는 이름으로 파일을 다시 넣게 한다(파일 이름에 Windows 금지 문자 `< > : " / \ | ? *`가 있으면 `_`로 바뀐다).
- 사용자가 첨부한 파일은 그 경로를 그대로 넘긴다. Windows 경로·공백·한글 파일명은 따옴표로 감싸 한 인자로 전달한다. 파일 이름은 Windows에서 쓸 수 있는 형태(NFC 한글)로 저장된다.
- 같은 음원(같은 sha256)은 다시 추가하지 않고 기존 id를 알려 준다.
- 곡 이름이 여러 곡에 맞으면 명령이 후보 id를 보여 준다. 사용자에게 어느 곡인지 묻는다.

## 편에 연결되는 것

`use`는 다음을 한 번에 한다. 다시 실행해도 기록이 겹치지 않는다.

1. `library/music/files/<파일>` → `news/<편>/02_production/external_assets/audio/bgm/<파일>` 복사(해시 대조)
2. `02_production/audio.json`의 `bgm.asset = "library:<id>"`, `bgm.file = "audio/<파일>"`, `bgm.credit` = 파일 이름(확장자 제외). 다른 믹스 값(gain·duck·fade)은 유지한다. audio.json이 없으면 sync 기본값으로 만든다.
3. `01_input/05_참고자료/RIGHTS.md`에 공용 목록 기록(출처·라이선스(없으면 "미기재")·사용 범위·끝 크레딧 줄·sha256)을 절로 추가
4. `visual-system.json` 끝 크레딧 마지막 장에 "음악" 줄(파일 이름) 추가 — 이후 `editorial:check`로 장 구성을 다시 확인한다. visual-system.json이 아직 없으면 넣지 않았다고 알려 주므로 화면 설계 뒤 `use`를 다시 실행한다

배경음악 음량·구간은 이전과 같이 audio.json에서 조정하고 [실물 검수](../../shortform-news-pipeline/reference/review-loop.md)대로 들어서 확인한다.

## 소싱에서의 순서

편의 배경음악을 고를 때 **공용 폴더를 먼저 조회한다**(`npm run music -- list`). 이야기의 정서·내레이션의 자리에 맞는 곡이 있으면 그 곡을 후보로 청취하고, 맞지 않거나 비어 있을 때 외부 음악 탐색([sourcing.md](sourcing.md))으로 넘어간다. 공용 곡을 쓰지 않았다면 그 이유를 소싱 후보표에 한 줄 남긴다. 공용 목록에 있다는 사실이 이번 편의 정서·자리 적합성을 대신하지 않는다. 라이선스 미기재는 후보 제외 사유가 아니다.

## 보관

- 음원 파일은 git에 올라가지 않는다. `library/music/files/`를 편 완성본(`out/pilots/*/deliver/`)과 함께 백업한다.
- 다른 컴퓨터에서 목록만 있고 파일이 없으면 `list`가 "없음(복원 필요)"로 보여 준다. 백업에서 같은 이름으로 복원한 뒤 `check`로 해시를 확인한다.
- `add`는 목록(`catalog.json`)만 명시해 자동 커밋한다(메시지 `공용 음원: <id> 추가`, 라이선스를 적었으면 뒤에 `(<라이선스>)`). 편 확정 커밋 범위와 별개이며 손으로 커밋하지 않는다. `use`가 바꾼 편 파일은 그 편의 확정 커밋에 함께 들어간다.
