# 기사 기반 위임 제작의 표현 선택 권한

`editorial-concept`에서 제작 에이전트가 설명과 표현 전체를 책임진다. 사용자 지시와 `story.creative_scope`를 먼저 읽는다. 근거는 제작 저장소의 `docs/research/2026-09-06-production-structure/raw.md`에 보존했다.

## 제작자가 결정할 것

- 질문·결론·설명 순서·원고·개념 수·장면 길이를 자료와 함께 설계하고 수정한다.
- 수집 영상·이미지·생성 자료·도해 중 해당 관계를 잘 설명하는 수단을 선택하거나 조합한다. 필요하면 이미 선택한 자료를 교체한다.
- 구도·위계·정보량·등장·퇴장·속도 곡선·내레이션의 호흡·BGM·효과음을 통합해서 판단한다.
- 공통 부품을 사용·변형하거나 편별 TSX/SVG 등으로 새 장면을 작성한다. 기존 부품 목록·이전 편의 좌표·컷 수는 새 표현의 범위를 정하지 않는다.

사실·조건·출처·사용 근거를 유지하고, 생성한 표현이 실제 관측 증거처럼 보이지 않게 한다. 주어진 위임 범위 안의 세부 선택은 진행하며, 이미 받은 승인을 반복해서 요구하지 않는다.

## 적용 규칙

| 구분 | 이 경로의 적용 |
|---|---|
| 자막·출력 | `visual-system.production_profile`로 제작 프로필을 참조한다. 실제 자막은 컴파일된 프로필 snapshot을 사용한다. |
| 설명·자료 | story/concepts와 편별 근거가 정본이다. 원고와 자료를 왕복할 수 있다. |
| 새 도해 | 편별 구현을 작성하고 실물 검수한다. legacy `shots` 등록 부품이나 `gate 4-3`을 요구하지 않는다. |
| 생성·교체 | 자료의 역할과 적합성, 사실·사용 근거로 판단한다. 수집판→생성판의 순서나 비트당 호출 수를 고정하지 않는다. |
| 모바일 정보량 | 동시에 읽을 대상을 설계하고 실제 모바일 화면으로 검수한다. 라벨 예산 초과는 검수 경고이며 정당한 표현을 막는 전역 개수 제한으로 쓰지 않는다. |
| 시간·모션 | 발화 앵커를 컴파일하고 장면·SFX·프루프가 같은 사건을 참조한다. 곡선·공간·거리·상태 유지 방식은 제작자가 설계한다. |
| 원고 수정 | 음성 생성 뒤에도 가능하다. 변경된 음성·발화·자막·모션·SFX를 다시 생성·검증한다. [작업 상태·재개](production-state.md)로 오래된 결과와 필요한 작업을 확인하고 실제 도구를 실행한다. 의미상의 추가 영향은 제작자가 표시한다. |
| 검수·수정 | 검수자는 오류와 이해·가독성 문제를 근거와 함께 남긴다. 제작자는 해결할 표현을 선택하고 수정·재검수한다. |
| 사용자 제출 | 완성 시안과 중요한 선택을 중심으로 보여준다. 내부 층별 승인을 완료 조건으로 추가하지 않는다. |

## 선택을 실행하는 경로

`story/concepts → narration → motion → editorial:check/compile → 편별 장면 → sync → 프루프·독립 검수·수정`을 사용한다. 자료나 프루프의 결과에 따라 이전 판단으로 돌아갈 수 있다.

현재 제작 프로필은 저장소 `config/production-profile.json`에 있다. 이전 버전은 `config/production-profiles/`에 보존하며 편의 id/version 참조대로 컴파일한다. 프로필 없는 이전 편의 데이터는 호환 경로를 유지한다. 신규 템플릿은 현재 프로필 참조를 포함한다. 새 기능과 후보 승격 여부는 구분하며, 독립 검수 없이 좋은 표현이라고 자동 판정하지 않는다.
