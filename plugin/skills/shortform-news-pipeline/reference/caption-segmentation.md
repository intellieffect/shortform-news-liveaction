# 고유명사·서술어 자막 분절

현재 `hani-shortform@1.5.0`의 `font-semantic@2` 계약이다. 배치 정본은 [공통 배치](../../../../config/layout-rules.md). 옛 프로필은 옛 분절을 유지하며 새 계약으로 자동 이행하지 않는다.

자막은 전부 보존한다. 고유명사는 묶고 서술어 앞에서 의미 단위로 나눈다. 폰트 크기·폭·안전영역을 바꾸거나 원문을 압축해서 해결하지 않는다. 자동 분절은 표면형 휴리스틱이므로 인용부호 없는 이름을 완전하게 인식하지 못한다. 제작자가 고유명사와 필요한 서술어 경계를 확인하고 다음 파일에 지정한다. 짧은 문장이 이미 한 줄에 맞으면 기계적으로 서술어만 떼지 않는다.

## 작성과 조립

편의 `02_production/caption-segmentation.json`은 선택 입력이다. 조립 명령이 파일을 자동으로 읽고, 없는 경우 자동 분절 후보를 만든다. 고유명사가 있는 원고는 명시적 보호 구간을 작성한다.

```json
{
  "schema_version": "1.0",
  "lines": {
    "s01": {
      "protected_phrases": [{"from": 5, "to": 8, "text": "국제 달 관측의 날"}],
      "break_before": [{"token": 9, "text": "열렸습니다."}]
    }
  }
}
```

위 색인은 `전세계가 함께 달을 올려다 본 국제 달 관측의 날이 열렸습니다.` 예시다. 예시를 현재 원고 대신 복사하지 않는다.

- 색인은 각 줄의 `caption_words`를 0부터 센다. `from`·`to`는 양끝을 포함한다. 보호할 `text`는 첫 토큰 안에서 시작해 마지막 토큰 안에서 끝나야 한다. 마지막 토큰에 조사나 서술어가 붙어 있어도 보호 범위는 토큰 전체다.
- `break_before`는 해당 토큰 앞의 분할이다. `text`는 실제 토큰과 정확히 같아야 한다. 보호 구간 안에 분할을 넣을 수 없다.
- 존재하지 않는 줄, 오래된 색인·문구, 겹친 보호 구간, 문장부호를 가로지르는 보호 구간은 오류다. 보호 구간은 0.8초 이상 쉼보다 우선한다.
- 음성·정렬·자막 원문은 유지하며 `npm run narration:assemble -- <id> --alignment 02_production/audio/alignment.json --replace`로 파생 자막을 재조립한다. 음성 재생성이나 렌더를 뜻하지 않는다. 출력의 `sentences[].caption_segmentation`과 입력 파일 해시가 근거로 남는다.
- 프로필 `@2` 검사는 원문 전체·실제 단어 시각·힌트로 재조립한 결과와 `captions`를 비교한다. 파생 자막만 손으로 바꾸지 않는다. 경계를 고칠 때 힌트를 고치고 재조립한다.

## 폭이 넘을 때

`국제 달 관측의 날이었습니다.`처럼 이름과 서술어가 한 시간 토큰에 붙고 보호 구간 전체가 폭을 넘으면 오류로 멈춘다. 토큰 내부 시각을 임의로 쪼개거나 자막을 줄이지 않는다. 기존 발화에서 정확한 경계를 확보할 수 있는지 먼저 확인한다. 원고·음성을 바꿔야 하는 경우는 그 편의 승인 범위를 확인해 별도 판단한다. 새 대본에서는 고유명사와 서술어를 분리하기 쉬운 문장으로 작성한다.

자동 분절의 어미·조사 판정은 형태소 분석이 아니다. 문맥에 맞는 의미 분할, 읽기 시간, 안전영역은 편별 검수에서 확인하며 데이터 검사 통과를 실물 검수로 대신하지 않는다.
