# 연구·평가용 제작 사례 보존

과거 선택과 결과의 비교를 연구·평가용으로 보존한다. 이 문서와 이미지 표본은 새 편의 시작·재개·검수 기본 입력에 포함하지 않는다. 현재 기사와 자료에 대한 판단은 제작자가 수행한다. 아래 기록의 실험 조건과 한계는 그대로 유지한다.

## 한 편의 질문과 자료 구성 — 메이븐 legacy / fresh

같은 임무 종료 기사를 다룬 두 영상이다. legacy는 이전 편들의 피드백이 누적된 세션, fresh는 기사와 제작 지시로 시작한 새 세션이었다. 사용자는 legacy를 높게, fresh의 설명·자료·표현 품질을 낮게 평가했다. 루트 모델 이름과 effort는 같았지만 문맥·자료 접근·실행 조건 전체가 통제된 실험은 아니다.

| 선택의 단계 | 관찰한 내용 |
|---|---|
| 초기 선택 | 양쪽의 공개 착수 설명은 임무 종료에서 시작해 화성 대기 손실을 설명하는 방향이었다. |
| 최종 이야기 | legacy는 물이 있던 화성의 변화와 물 손실의 질문 → 탐사선의 조사 → 대기와 물 손실의 과정 → 남은 연구 기록으로 이어졌다. fresh는 예정 임무와 실제 활동 기간을 먼저 소개했다. 기간 대비도 가능한 도입이며 그 자체가 오류는 아니다. |
| 자료 선택 | legacy는 화성의 과거/현재, 탐사선 도착, 태양풍 개요의 NASA 영상들을 각기 다른 역할로 사용했다. 큰 규모의 현상에서 미시 과정으로 들어갈 때 자료와 도해가 설명을 이어받았다. |
| 실물에서 발견한 문제 | legacy 제작자는 탐사선 장면이 길게 이어진다는 문제를 보고하고, ‘남겨진 기록’부터 대기 자료로 넘어가도록 변경했다. 최종 코드에도 그 전환이 남았다. |
| 다른 결과 | fresh는 실제 공식 영상 다운로드 실패 뒤 사진과 도해를 사용했다. 여러 검수와 자막·겹침 수정을 했지만 결말의 추상성 관찰에는 ‘필수 결함이 아니므로 유지’했다고 응답했다. |
| 이 사례가 여는 판단 | 초안의 사실이 맞고 개별 화면이 구현됐어도, 관심이 이어지는 방식에 따라 질문·자료·순서를 다시 선택할 수 있다. 영상 확보 실패는 표현 조건을 바꾸므로 남은 자료에서 한 편을 어떻게 설명할지도 다시 판단한다. |

같은 시점의 도입 표본이다. 정지 표본으로 연속 움직임이나 음향을 검증할 수는 없다.

| legacy | fresh |
|---|---|
| ![legacy 도입](../assets/editorial-examples/legacy-opening.jpg) | ![fresh 도입](../assets/editorial-examples/fresh-opening.jpg) |

옮길 것은 ‘항상 질문으로 시작’이나 ‘영상 세 개 사용’이 아니다. 시청자가 궁금해진 것과 자료·설명의 진전이 이어지는지, 실제 시안에서 약해졌을 때 수정 범위를 어디까지 열어두는지를 참고한다. 사용자 호평과 공개 수정 기록은 근거지만 품질 차이의 단일 원인은 분리하지 못했다.

## 한 과정의 이해 — 물 손실 new

fresh의 물 손실 구간은 작은 분자 여러 개·상승 화살표·큰 설명 문구가 함께 있었다. 후속 new 세션에는 비교 화면과 성공/실패의 구체적 차이를 제공하고 기존 원고·음성을 사용한 짧은 구간 제작을 맡겼다.

| 선택의 단계 | 관찰한 내용 |
|---|---|
| 설명할 변화 | 물 분자가 더 높이 올라가고, 분해된 뒤 수소가 빠져나간다. |
| 새 설계 | 큰 분자 하나를 추적하고 ‘평소’ 위치를 비교 기준으로 남겼다. 확대해도 대상의 색·형태를 유지했다. 분해를 읽는 시간과 수소의 탈출을 구분했다. |
| 시안 후 수정 | 배경 절단선·약한 먼지 대비·비교 표시를 고치고, 상층에 남은 가열선과 의미가 불분명한 충돌 입자를 정리했다. 산소만 남는 종결도 수정했다. |
| 결과와 범위 | 사용자는 15.5초 시안을 높게 평가했다. 외부 영상·이미지 재생성, 새 TTS 없이 도해와 기존 발화의 호흡을 수정했다. 전체 기사의 이야기·자료 선택과 BGM·SFX 품질은 이 실험의 검증 범위가 아니었다. |

![상승 비교 — 왼쪽 fresh, 오른쪽 new](../assets/editorial-examples/water-rise.jpg)

![분해 비교 — 왼쪽 fresh, 오른쪽 new](../assets/editorial-examples/water-split.jpg)

이 사례는 모든 과정을 분자 하나나 같은 색으로 표현하라는 뜻이 아니다. 시청자가 따라갈 대상을 유지하고 서로 다른 사건을 읽을 여유를 주는 선택을 보여준다. 구체적인 비교 방향을 받은 실험이므로 아무 단서 없이 해법을 재발견한 증거로 해석하지 않는다.

## 근거의 위치와 한계

제작 저장소의 `docs/research/2026-09-06-maven-session-gap/`, `2026-09-06-maven-new-result/`, `2026-09-06-production-approach-gap/` (과거 내부 기록·로컬 보관)에 사용자 원문·전달문·공개 작업 기록·원본 영상 해시가 있다. 위 표본은 [복사 출처와 해시](../assets/editorial-examples/sources.json)로 연결한다. 설치 패키지에는 이 설명과 표본이 함께 들어가므로 별도 워크트리가 없어도 사례를 읽을 수 있다.

영상 전체 연속 시청·청취가 입증되지 않은 범위를 이 문서가 완료 처리하지 않는다. 실제 다음 편에서는 [실물 검수](review-loop.md)로 해당 결과를 확인한다. 좋은 도해 한 장면과 좋은 한 편 전체를 구분해 검증한다.
