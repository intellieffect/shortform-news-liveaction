# Higgsfield 생성 활용

생성 영상, 설명용 이미지, 투명 배경 오브젝트·오버레이, 모션그래픽의 외형과 동작 자산은 Higgsfield에서 제작한다. 실제 호출 가능한 도구와 계정을 확인하고 작업에 적합한 모델을 고른다. 특정 모델이 현재 지원된다고 추측하지 않는다. 기본 경로는 현재 세션에 연결된 Higgsfield 커넥터 도구다(README의 «생성 서비스 연결»). 커넥터가 없으면 브라우저로 직접 작업할 수 있으나, 어떤 브라우저를 쓸지는 이 저장소가 정하지 않는다 — 현재 호스트에 연결된 도구를 확인하고 없으면 제작자에게 알린다.

이미지·일러스트·오버레이의 스타일과 장면 합성은 [시각 표현 안내](visual-expression.md)를 따른다. 코드로 표현하기 어려운 외형뿐 아니라 미술 완성도·몰입에 적합한 재료를 만들 때도 Higgsfield를 선택할 수 있다. 코드 구현을 먼저 시도하거나 모든 장면에 생성 자산을 넣을 의무는 없다. 독립적으로 움직일 대상은 필요에 따라 분리 생성하고, 투명 배경·가장자리·해상도는 실제 출력과 최종 합성에서 확인한다.

관측·고유 대상·수치의 근거는 공식 원본에서 확보한다. 생성물은 관측 증거로 제시하지 않는다. 배경·은유·설명용 재구성에는 생성물을 쓸 수 있으며 사실 조건을 보존한다.

- 영상: 방향·연속 동작·공간 변화가 필요한 구간에 사용하고, 인과나 고유 형태가 어긋나면 재생성 또는 코드/다른 자료로 바꾼다.
- 이미지·오버레이: 피사체 외형·재질·조명을 만들고 합성에 필요한 배경·여백·가림을 설계한다. 잘라낼 수 있는지 실제 가장자리를 확인한다.
- 정보그래픽·도해: 생성 자산으로 외형을 확보하고 정확한 숫자·단위·인용·축·개수·관계·등장 시각은 코드 합성으로 제어한다. 생성된 완성 그림을 흔드는 것만으로 과정 설명을 대신하지 않는다.
- 3D 도구 금지: Higgsfield 안의 Blender·3D 도구(`scene_builder_3d_*`, `generate_3d`)로 도해를 만들지 않는다. 도해가 필요하면 생성 영상·실사 대비·코드 합성 중에서 고른다. 사용자 지시 원문(2026-09-23): "higgsfield 내에서 블렌더와 같은 3d 도구는 사용하지 않도록 해". 경위: hani_1278583 충돌구 그림자 도해를 3D로 시도했을 때 원격 워커가 프레임당 25초 이상 걸려 5분 한도에서 6프레임 렌더도 시간 초과됐다.

필요한 행동의 시작·작용·결과가 실제 화면에서 읽히는지 먼저 확인한다. 생성·코드·실사를 사용했다는 사실 자체는 품질 통과가 아니다. 재료 스타일은 이번 기사와 프로젝트 기준에 맞춰 선택하며 종이 스타일을 자동 적용하지 않는다.

내레이션은 Typecast를 기본으로 하며 제공 WAV가 있으면 그대로 사용·정렬한다. Typecast를 쓸 수 없으면 Higgsfield 오디오를 대안으로 확인한다. 공급자 변경과 실제 음성·정렬·속도 조절은 기록한다.

편의 제작 노트에 실제 제공자/모델, 최종 프롬프트, 참조 파일, 출력 원본, 채택 구간, 비용과 수정 이유를 남긴다. 원본을 보존하고 파생본만 가공한다. 실제 생성 요청은 전체 제작 위임 범위에서 수행하며 추가 사용자 승인 단계를 만들지 않는다.

새 제작은 [발화→화면 제작](visual-production.md)의 generation_jobs와 채택 자산을 연결한다. 생성한 배경 이미지나 TTS만으로 설명 모션그래픽을 만들었다고 기록하지 않는다. 정확한 정보는 코드로 제어하되, 빛·물질·변형의 움직임 전체를 생성하고 코드로 합성하는 방식도 먼저 검토한다.
