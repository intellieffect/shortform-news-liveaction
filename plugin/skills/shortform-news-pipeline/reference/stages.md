# 단계 (파일럿 1편의 전체 순서)

## 모드 분기

아래 표는 `script-faithful@1`의 상세 단계다. 기사 기반 제작을 위임받은 `editorial-concept@1`은 **원문·사실·제약 → story → concepts/표현 선택 → 원고 잠금·내레이션 → motion/timeline → 통합 제작 → 내부 P5/P7 검수·수정 → 완성 시안과 중요한 선택 → 보존** 순서로 간다. 3′과 4-3R의 판단은 내부 검수로 흡수하고, 권리·사실·새 비용·목표 변경만 사용자 결정으로 남긴다. 전체 절차는 [editorial-concept-track.md](editorial-concept-track.md), 검수는 [review-loop.md](review-loop.md)가 정본이다.

| 단계 | 담당 | 입력 | 산출물 | 넘어가는 조건 |
|---|---|---|---|---|

**0~2 를 건너뛰고 코드부터 쓰면 되돌리기가 비싸져 숫자만 조정하며 버티게 된다.** 5편이 b14·b15 에서 3판을 갈았다.

0. **비트마다 3단 판정**(§5c) → **`layer43_plan[b].tier` 에 값으로**(`1|2|3a|3b|3c`) + 사유는 `why`. 값이라 넉 자 적고 넘어갈 수 없다 — `"3단 판정"` 문자열 검사(check-shots)는 그 우회가 가능했다.
1. **실사부터 다시 뒤진다** — 기관 미디어 키트의 **미사용분**·논문 도판·시뮬레이션 영상까지. 5편은 NASA SDO 52~61초와 논문 도판 상단 패널이 이미 있었는데 안 찾고 그렸다. **게이트가 `assets.json` 등재분 중 shots 에 안 쓰인 것을 목록으로 뽑아 준다** — 5편 착수 시점에 15건이 떠 있었다.
2. **MC 를 쓰면 씬 계약을 먼저 쓴다** — `<root>/02_production/mc_spec.md`(템플릿 `templates/mc_spec.md`). 씬 tsx 보다 **먼저**. 단일 세션이라 상대가 없어도 쓴다 — 값은 인계가 아니라 **구현이 계약을 고치지 못하게 하는 것**이다. 요소 `[x0,y0,x1,y1]`(2D — y 대역만으로는 나란히 놓은 요소를 오탐하고 x 충돌을 놓친다) · `allow_overlap` · `claims` · `occludes`. 텍스트 폭은 1회 렌더 후 **실측 되기입**, 애니메이션은 **여러 시점 union**. 검사 `npm run mc:check -- <root>`.
2b. **레퍼런스 → 시안 → 구현**(§5c). 레퍼런스는 `layer43_plan[b].ref` 에 적는다(tier 1·3b 필수, 게이트 E6). 시안은 **실제 배경·자막 위에 얹어** 정지로 뽑는다(`--scale=0.36`, 안당 8초). 폐기 시안은 사유와 함께 부품 주석에.
3. **구현** — 형태 계약 `DIAGRAM`·색 계약 `BRIGHT_TUBE` 안에서만. 부품 안에서 새 숫자를 만들지 않는다. 부피가 있는 대상은 `@remotion/three`(`Config.setChromiumOpenGlRenderer("angle")` 필수).
4. **registry 등록은 구현 **전**에** — 필수 필드(`bind`·`impl`·`props`·`draw_tier` 포함)를 채우고 시작한다. 사후 stub 금지.
5. **검증** — `shots:check` 0 · `layout:43 --check` 0 · **`mc:check` 0**(MC 쓰면) · **비트시트**(3.4초)로 전편을 이어서 본다.
