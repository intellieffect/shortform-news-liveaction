# 제작자와 전문 에이전트

한 제작자가 전체 이야기·원고·자료·표현·음향을 책임진다. 소싱 담당은 선택에 필요한 후보와 한계를, 검수자는 독립적으로 관찰한 문제를 돌려준다. 제작자는 그 근거로 수정 범위를 정한다.

`@agent-shortform-news:<name>`으로 부른다. 실제 호출 수단은 현재 호스트에서 확인한다. 지정 시점의 상시 호출 권한은 제작 저장소 `CLAUDE.md`를 따른다. 새 역할이나 추가 호출 권한을 이 문서가 부여하지 않는다. 병렬 호출은 한 메시지에서 실행한다.

## 호출 시점과 입력

| 역할 | 시점 | 입력과 결과 |
|---|---|---|
| `source-verify` | P0, 기사·자산 목록 확보 후. 원문 보존과 병렬 | 기사 원문·게재 자산 → 자산별 권리와 1차 출처 대조 |
| `sourcing` | P3, 종류별 gaps 확보 후 영상·사진·음악 병렬 | 모드·전체 목적·담당 자료 역할·facts·gaps → 실물 확인한 후보, 기각·미확보·요청 범위의 한계 |
| `editorial-judge` | editorial-concept, 초안·facts·자료 후보 확보 후 TTS 전 | 원고·자료 후보를 먼저 읽고 story/concepts 의도와 대조 → 전체 이야기와 개념 설명의 문제 |
| `shot-judge` | P4·P5·P7 | 현재 모드에 맞는 실물 입력 → 화면·설명·흐름 관찰과 확인 범위. P7은 fact-check와 병렬 |
| `fact-check` | P7 | 최종 영상의 주장·자료·도해와 facts → 근거·조건·불확실성 오류와 미확인 범위 |

## editorial-concept

- 소싱 입력은 [자료 선택과 수집](../../shortform-news-input/reference/sourcing.md)을 따른다. 전체 이야기의 맥락을 유지한 채 전문 작업을 나눈다. `kw`·문장별 컷·실사 소진표로 탐색 범위를 고정하지 않는다.
- 화면 검수 입력은 [실물 검수·수정](review-loop.md)의 `review-input` 명령으로 구성한다. 먼저 실제 시안의 관찰을 받은 뒤 같은 입력의 의도·사실 대조를 연결한다. 실제 호출은 제작자가 현재 호스트의 지정 에이전트 도구로 수행한다. 원해상·모바일 표본과 연속 시청·청취는 서로 다른 확인 범위다.
- 검수자는 결함과 경험이 약해진 현상을 보고한다. 개별 개념뿐 아니라 전체 이야기의 진전·자료 구성·결말도 검토하며, 특정 표현이나 비율을 처방하지 않는다.
- 제작자는 수정 표현과 범위를 결정한다. 원래 이슈를 보존한 채 자신의 응답을 덧붙이고 실물로 재검수한다. 원고·BGM·생성·세부 연출이 위임돼 있으면 단계마다 사용자 선택으로 돌리지 않는다.

## 공통 보존과 책임

- 소싱 후보는 제작자도 실물로 확인한다. 원자료는 파일에 보존하고 대화에는 후보표와 근거 경로를 반환한다. 클립은 타임코드가 있는 여러 표본과 실제 확인 가능한 구간으로 판단한다.
- 검수 에이전트는 제작물을 편집하지 않는다. 판정 원문을 수정·축소하거나 제작자 결론으로 대체하지 않는다. 사용자에게 보고하는 이슈는 원문을 유지하고 수정 결과를 별도로 붙인다.
- 제작 중 확인된 오류는 위임 범위에서 해결한다. 사용자에게는 완성 시안, 중요한 방향 선택과 미해결 한계를 중심으로 보여준다. 검수 원문 전체는 기록으로 연결한다.
- 사용자 고정 조건·사실·권리와 표현 선택을 구별한다. 원고·음성·자료가 바뀌면 영향받은 시간축과 검수 결과를 갱신한다.
- 새 문제는 원인과 수정 결과를 먼저 기록한다. 반복 가능한 기술 오류는 [개정 지침](maintenance.md)에 따라 가드 후보로 검증하고, 편별 연출 판단은 사례로 남긴다. 모든 피드백을 전역 금지 규칙으로 바꾸지 않는다.

## script-faithful

제공 대본·컷의 준수 범위와 사용자에게 남겨진 선택은 이번 요청으로 정한다. 비트 경로의 소싱 순서·A/B 판정·`layer43_plan[b].why` 입력은 [기존 제작 경로](script-faithful-track.md)와 각 에이전트의 해당 모드 절을 따른다. 원고·BGM 등을 사용자가 선택하기로 한 편에서 그 단계를 유지한다. 이 절의 단계별 입력·승인을 기사 위임 제작에 가져오지 않는다.
