# 고정 커버 스타일 — 제목과 로고 영역

이 채널의 기본 썸네일은 **두 줄 제목과 하단 중앙 로고 영역을 둔 세로형 생성 커버**다. 다음 기준을 매 편 자동으로 적용한다. 사용자가 새 스타일을 요청하면 그 지시를 우선한다. 장면과 문구는 영상에 맞게 설계하되 제목과 로고 영역을 다시 탐색하지 않는다. 로고 미수령 표시와 후보 세 장 제출은 2026-09-07 사용자 요청으로 추가했다.

## 고정할 것

| 항목 | 기준 |
|---|---|
| 화면 | 세로 9:16, 어두운 남색 바탕 |
| 서체·굵기 | 아래 기준 PNG의 굵은 한국어 고딕 인상. Pretendard ExtraBold 800은 생성 프롬프트용 근사 설명이며 실제 폰트 파일을 사용했다는 뜻은 아니다 |
| 배치 | 두 줄 모두 왼쪽 정렬. 왼쪽 여백 약 화면 폭의 7%, 첫 줄 글자 상단 약 화면 높이의 18%, 둘째 줄 약 24% |
| 크기 | 기준 PNG의 같은 시각 크기와 줄 간격을 유지한다. 문구가 짧다고 키우거나 긴 문구를 과도하게 압축하지 않는다. 문구는 두 줄 안에 맞게 설계한다 |
| 강조 | 첫 줄 흰색, 둘째 줄 전체 연두색. 생성 프롬프트의 색 기준은 #FFFFFF / #B6F24A. 단어·숫자만 따로 확대하거나 다른 강조색을 추가하지 않는다 |
| 로고 영역 | 하단 중앙. 왼쪽 30%, 위쪽 91%, 폭 40%, 높이 6%의 공통 영역을 확보한다. 핵심 장면은 높이 88% 위에서 끝나도록 배치한다 |
| 로고 미수령 | 위 영역에 얇은 회색 점선 사각형과 중앙의 작은 회색 ‘로고 영역’ 문구를 표시한다. 실제 로고처럼 꾸미거나 임의 브랜드를 만들지 않는다 |
| 로고 수령 후 | 점선과 문구를 제거하고 제공 로고를 같은 영역 안에 비율 유지해 배치한다. 로고 원본을 생성으로 다시 그리지 않으며 원본 형태를 확인한다 |
| 추가 텍스트 | 제목과 로고 또는 미수령 표시 외에 장면 라벨, 하단 설명, 출처, ‘개념도’·‘재구성’ 주석, 배지 문구를 넣지 않는다. 사용자가 별도로 요청한 추가 문구만 예외다 |

## 생성에 넣을 기준 이미지

[커피·태양](../assets/cover-style/solar-swirl.png)을 공통 제목·배치의 기본 기준 이미지로 사용한다. [은하](../assets/cover-style/disc-flip.png)와 [우주 택배](../assets/cover-style/starfall.png)는 다른 소재에도 같은 제목 스타일을 적용한 예시다. 세 이미지를 모두 넣는 것을 기본으로 하지 않는다.

기준 PNG를 실제로 열고 `role: "style"`로 전달한다. “제목의 서체 인상·크기·위치·흰색/연두색·줄 간격은 유지하고, 문구 내용과 중앙 장면만 이번 영상에 맞게 바꾼다. 문구 길이에 따라 오른쪽 끝만 달라진다. 하단 중앙에는 고정 로고 영역을 확보하며, 제목과 로고 또는 미수령 표시 외 텍스트는 없다”를 생성 지시문에 연결한다. 기준 PNG에는 로고 영역이 없으므로 위 로고 규격을 별도로 적용한다. 기준 이미지 속 커피·태양, 두 패널 구성, 문구를 다른 영상에 그대로 가져오지 않는다.

기준 PNG의 고정 범위는 제목과 로고 배치다. 중앙 장면의 질감·발광·과장 강도는 물리적 표현 기준으로 복제하지 않으며, 이번 소재의 [표현력과 실물의 신뢰성](cover.md#표현력과-실물의-신뢰성을-함께-설계한다)에 맞게 선택한다.

기준 PNG는 생성 입력과 내부 검수용이다. 사용자 제출 이미지·비교 화면에는 넣지 않는다. 사용자가 참고 이미지를 별도로 요청하면 그 요청을 따른다.

위 비율은 기준 이미지를 설명하는 근사값이며 **실제 PNG의 인상이 우선**이다. 현재 기준 PNG는 941×1672다. 요청 해상도와 실제 반환 크기를 구분한다. 생성 지시만으로 정확한 폰트·좌표·색의 픽셀 일치를 보장했다고 기록하지 않는다.

## 유지할 판단

이미지 자체가 제목의 비교·변화·관계를 보여주도록 설계한다. 부수적인 글자가 없으면 오해되는 구성은 장면이나 제목에서 해결한다. 재구성·개념 여부, 출처·권리와 사실의 한계는 제작 기록과 배포 설명에 보관하며, 생성한 장면을 실제 관측 증거로 제시하지 않는다.

내부 검수에서는 결과를 기준 PNG와 같은 표시 크기로 놓고 제목의 시작 위치·글자 크기·색·줄바꿈을 확인한다. 후보끼리 로고 영역 위치·크기가 유사하고 장면과 겹치지 않는지도 확인한다. 제목과 허용된 로고 표시 외 글자가 생겼으면 제거한다. 로고 좌표도 생성 결과에서 확인하며 픽셀 일치를 보장하지 않는다. 검수는 실물을 보고 수행하며 새로운 가드나 승인 단계를 만들지 않는다.
