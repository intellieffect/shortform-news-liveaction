## §8 크레딧·라이선스

- **R8-02 (U9) 엔드카드 크레딧은 실사용분에서 파생한다** — `npm run credits`(순서 = 등장순, 라이선스 태그는 assets.json 역참조, 음악은 audio.json). **자산이 화면에서 빠지면 크레딧도 빠진다.** 마감 게이트 = `--check` exit 0. ✓ 기사 줄은 `pilot.json.article{outlet,byline,date}` 에서 자동, 발표·논문 줄은 `--extra "…\n…"`(여러 줄) — **명령을 `02_production/credits.cmd.txt` 에 적어 두고 `--check` 도 같은 인자로**(인자가 다르면 줄이 어긋나 exit 1). CC BY-SA·IGO 는 원문대로 표기된다(2026-09-02 6편 정정)
- **R8-03 (U9) AI 고지는 엔드카드 크레딧에만** — 생성 비트는 `credit: null`, 엔드카드에 1줄(범위 한정 「배경·예시 영상 AI 생성」). i2v 시작 프레임 자산은 `시작 이미지: <credit>`. 화면 라벨 「AI 시각화 · 개념도」는 **폐기**(2026-08-30). ✓ `[ai-notice-endcard]`

## §10 최종 검토 체크리스트 (4-6)

| 분류 | 확인 항목 |
|---|---|
| A 버그 | 계획 placeholder·비트 태그 잔존, 그래픽 잘림, 크레딧 누락·고아, 인셋 라벨 줄바꿈, 원본 인쇄 글자 잔존 |
| B 가독성 | 밝은 배경 위 자막, 같은 숫자 두 번, 4겹 과밀, 문서 크롭 판독, 엔드카드 읽을 시간, 온스크린 = 자막 확대판, 같은 라벨 연속 |
| C 구성 | 산만한 배경, 검은 화면 비트, 인용 블록 치우침, 디졸브 자막 공백, 약한 근거 화면, 인셋 역할 없음, 한 사실 두 비트, 효과 되감김 |
| D 오디오 | 첫 1초 레벨, 무음 구간 BGM 유무, whoosh 횟수, 엔드카드 페이드, BGM 안 들림, 인용 구간 덕 |

**R10-01 읽기 속도 기준** — 평균 **6~7자/초**. 인용 카드는 앞 문장 유지로 노출 시간을 확보한다(**13자/초는 읽을 수 없다**). 4-2 객관 확인은 무텍스트 구간(비트 시작~첫 줄 >0.35s)·8자/s 초과 줄·0.6s 미만 줄·팝이 줄 교체에 잘리는 강조어를 `beats`·`overlays` 로 계산한다. ✗

수정은 한 번에 묶어 재렌더 → 프레임 재확인 → `audio.json.measured`·INDEX 기록. 검토 스크립트·이슈 스윕은 [commands.md](commands.md).


## §12 커버(썸네일) — 단계 9

판단은 [cover.md](cover.md), 실행과 검수는 [cover-build.md](cover-build.md)가 단일 소스다.

- 영상 자막의 줄 수·폰트 크기·글자 수를 커버 제목에 적용하지 않는다. 제목과 핵심 장면이 작은 화면에서 함께 읽히도록 설계한다.
- 커버에서 쓴 원본 자료의 출처·사용 조건과 생성·재구성 범위를 `manifest.json`에 기록한다. 필요한 개념도·재구성 표시는 커버에서도 읽히게 한다. 영상의 'AI 고지는 엔드카드에만' 규칙을 독립 이미지에 적용하지 않는다.
- **✗사람만 — 커버 출처 검수.** `npm run credits --check`는 영상의 shots 기반 검사다. 커버 자산과 생성 기록을 자동으로 검증하지 않는다. 각 입력의 사용 조건에 맞는 표기를 출력본·함께 전달할 설명에 반영하고 직접 확인한다.

## §13 납품본은 주 작업트리에 있어야 한다 (2026-09-05)

**워크트리는 지워지는 것이 정상이고 `out/` 은 gitignore 다.** 납품본이 워크트리에만 남으면
워크트리를 지우는 순간 같이 사라진다 — 2026-09-03 에 그렇게 `deliver/v1·v2·v3`·마스터·커버·
클립 1.1GB·`narration.wav` 가 한 번에 없어졌다. 그 뒤 만든 `worktree:remove` 가 막아 주지만,
**막는 것과 옮겨 두는 것은 다르다.** 9편·8편 모두 확정 뒤에도 워크트리에만 있었다.

- `npm run out:deliver` 가 워크트리에서 돌면 **주 작업트리로도 복사한다**(자동, 2026-09-05)
- `npm run worktree:remove` 는 목적지를 세어 **이관된 것만 통과**시킨다
- 확정 시점의 확인: `ls <주 작업트리>/out/pilots/<id>/deliver/`

납품본만이 아니라 `narration.wav` 도 재현이 안 된다(TTS seed 없음) — 함께 옮긴다.
