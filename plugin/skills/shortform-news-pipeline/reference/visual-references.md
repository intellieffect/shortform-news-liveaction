# 모든 제작의 공통 표현 레퍼런스

시작·재개의 context.reference_library는 저장소에 포함된 실제 공통 세트와 해설을 제공한다. 모든 새 영상에서 연출 설계 전에 지정 영상을 모두 확인한다. 규모·사진 확대·산란이라는 분류는 열람 조건이 아니다. 목적은 각 컷과 전체 영상에서 에이전트의 표현 선택과 결과 수준을 넓히는 것이다.

## 실물 확인

status preserved는 기준 버전을 보존했다는 뜻이며 열람 완료가 아니다. 세트의 guide_text, cases의 실제 MP4와 walkthrough 타임코드를 확인한다. 영상 인식 수단이 없으면 가능한 프레임과 타임코드/코드로 확인하고 실제 범위만 기존 direction.md/decisions.md에 기록한다. 같은 세션에서 변경 없는 자료를 재개할 때마다 다시 재생할 필요는 없다. missing/invalid이면 납품/LFS/고정 버전을 복구하거나 미확보 상태를 명확히 남기며, 예전 버전으로 조용히 대체하지 않는다. legacy-current-guidance는 새 작업용 안내이며 과거 열람 증거가 아니다.

## 기사별 판단

레퍼런스는 **이번 장면에 적용된 형태로만** 쓸모가 있다. 확인한 뒤에는 이번 편에서 실제로 가져올 판단을 한둘 고르고, 그것이 이 장면에서 무엇으로 나타나야 하는지와 어느 수준이면 충족인지를 기존 제작 노트에 한두 줄로 남긴다. 어느 사례에서 왔는지도 함께 적어 나중에 되짚을 수 있게 한다. 컷마다·사례마다 채우는 점검표나 별도 보고서가 아니고, 열람 사실을 다시 적는 기록도 아니다. 가져올 판단이 없는 구간에는 억지로 만들지 않는다.

각 구간이 이해시킬 내용과 확보 자료에서 구도·재료·표현을 선택한다. 레퍼런스의 정보 위계, 시선 유도와 맥락, 원인-작용-결과, 실사 합성, 발화와 움직임의 연결을 다른 기사에도 적용한다. 복잡한 핵심 구간은 익숙한 첫 표현 외의 접근도 검토하고 중요한 판단만 기존 제작 노트에 남긴다. 색·선·라벨·등장 효과·컷 수·오버레이 사용량·후보 개수를 고정하지 않는다. 실사 자체로 진행할 구간도 판단하며, 필요한 생성 재료는 기존 Higgsfield 지침을 따른다. 기존 concepts/motion 정본을 사용하며 컷마다 새 보고서를 요구하지 않는다.

## 전체 영상과 검수

실제 배경·고정 자막과 합성한 시안에서 판단한다. 전체 영상의 설명 진전, 반복과 호흡, 연결, 도입·결말·음향은 기존 검수를 유지한다. 세 짧은 장면이 전체 서사 품질의 증거는 아니다.

검수자의 experience 첫 관찰에는 이번 시안만 전달하고, 돌아온 관찰은 원문 그대로 보존한다. intent 대조에는 같은 공통 기준 세트와 이번 편에 적용하기로 한 판단을 함께 붙여 설명·미술·모션 완성도를 비교한다. 유사도나 기법 수로 통과시키지 않는다. 사용자 확정, 실제 확인 범위와 검수 판정은 구별한다. 기존 수정·재검수 흐름을 따르고 새 사용자 승인 관문은 만들지 않는다.

## 버전

start는 현재 세트와 설명을 00_brief/visual-references.json에 보존하며 request.json에 해시를 기록한다. resume과 intent는 같은 버전을 사용한다. 새 기준 세트가 나와도 진행 중인 편을 자동 교체하지 않는다. 개별 확정 버전 파일을 덮어쓰지 않고 다음 버전을 추가한다. 좋은 신규 표현은 사용자 확정 후 라이브러리 후보로 추가하며 남은 슬롯 수를 채우기 위해 만들지 않는다.
