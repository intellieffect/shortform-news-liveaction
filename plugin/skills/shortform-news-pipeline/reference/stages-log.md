## 단계별로 굳어진 것

> **편 이름으로 절을 만들지 않는다** — 새 편의 결정은 **해당 단계 아래 한 줄**로 들어가고 꼬리표 `(N편)` 으로 출신을 남긴다.
> 절을 편마다 더하면 문서 구조가 「최신 편이 규칙을 만든다」를 부른다([maintenance §7](maintenance.md), 실패 모드 F5).

### 0~1 입력·대본

**클라이언트가 URL만 준 경우** (3편 — 0~1단계 변형)

- input이 **제작용 문서**(한겨레 양식: 썸네일 문구 / 타임라인 표 시간·내레이션·화면 구성 제안·자막 / 러닝타임 / 참고 메모 / 참고자료 목록)를 쓴다. 컷마다 facts 번호(#N·C·Q)를 단다. 우리가 쓴 대본은 "고쳐 쓰지 않는다" 전제가 없다 — facts.md가 유일한 근거 장치.
- 러닝타임은 자수 추정이 아니라 **TTS 실측**으로 잡는다(이 보이스 Sanghyun ≈ 450자/분; 336자/분 추정은 30% 틀렸다).
- `cut_map`/`script_cuts.json` 없음. assets는 `cut_fit{primary,alt}` + 최상위 `cut_map`(컷=문장 1:1) 또는 `sentence_fit`. `rights_status`는 영문 값(cleared/unconfirmed/unused/rejected)만 — 한글 값은 gaps가 registry에 포함시킨다.
- 1차 출처(ESO 보도자료 등)가 CC BY면 기사 게재 사진보다 그 원본을 먼저 확보한다 — 사용권 리스크를 없앤다.

### 3 제작안·시트

- 비트 단위 슬라이드로 층을 쌓아 확정한 뒤 영상으로 잇는다 — 모션·VFX 는 나중 (1편)
- **완성 대본이 있으면 대본이 원고** — 자막 열 = 온스크린 문구의 단일 소스, 참고자료 컷 = `cut_map`(소싱 제외), 화면 구성 제안 = 슬라이드 패널에 원문 그대로 (2편, rules R1-03·R7-01)
- **온스크린 ≠ 자막** · **한 사실 = 한 비트 = 한 표현**(`layer43_plan` 단일 소스) · **인셋 = 키워드 실물**(배경이 이미 보여주면 없음) · **텍스트 걷어내기** (2편, rules R1-03·R1-04·R5-04·§5b)
- 실사 우선 소싱을 표준으로. 부품은 레지스트리로 자산화 (1편)
- 3단계 검토 산출물은 **`slides`(html)** 가 기본 — PNG 시트는 에이전트가 프레임을 **읽어야** 할 때만 (5편 U1)

시트를 띄우기 전에 비트마다 답한다: ① 문장의 **키워드 실물**이 배경에 있나 ② 인셋이면 **전면으로 못 가는 이유**가 있나(저해상·한 비트 두 키워드만 인셋 허용) ③ 배경이 없는(검정·타이포 단독) 비트는 **사유**가 plan.rules에 있나. 사용자 지적은 이 셋이었다.


### 4 조립 (4-0~4-6)

- 자막은 한 번에 한 줄·의미 단위 줄바꿈·중앙 정렬, 팝은 핵심 수치만. 인용은 한 블록(앞 문장 유지), 헤드라인 프레임 0·킥커 없음, CTA 엔드카드까지 유지 (1편, rules §1·§3 · registry)
- 전환: 씬 경계만 디졸브 8f, 나가는 텍스트는 컷, 인용 카드만 0.5s 연장(`keep_text`) (1편, layers §4-4)
- BGM: 제목이 아니라 mood×오디오 특징으로 재채점 → 인트로 무음만큼 `start_offset`. 레벨은 **발화 중 내레이션 −12~−15 dB 아래**, 확정은 사용자 청취 (1·2편, `audio.schema.md` 4c~4f)
- **효과 부품은 컷당 1회**(reveal 되감김), 보조 텍스트 44px 하한은 부품 구현에서 강제 (2편, rules R5-08)
- **원본에 인쇄된 글자(방위 문자·타임스탬프)는 크롭으로 배제**, 원본 무수정 (2편, rules §U13)

사용자가 "4~7단계 내용을 미리 볼 수 있나"를 물으면 `render.config layers` 전부 true로 **미리보기 렌더(crf 26)** 를 한 번 돌리고, 층별 객관 확인(4-2 스크립트·4-3 프레임·4-4 경계·4-5 구간 라우드니스)을 그 렌더로 한 번에 답한다. 층별 순서는 유지하되 렌더 횟수를 줄인다.

- 자막 강조 색은 핵심어만, 조사·구두점 흰색. / 온스크린이 자막과 **동일 텍스트**일 때만 자막 생략. / 대상 자체(에아렌딜-1)를 말하는 비트엔 공개 게재본 제품 이미지. / 수치 그래픽의 점은 수치에 비례 누적. / 도해는 자막 밴드(0.66) 위에서 끝나고 면 불투명도로 자막을 살린다(b04).


- **4-3R 검수판이 4-3 과 4-4 사이에 있다**(6편 신설) — 비트시트는 후보를 찾는 도구이고, 도해·인셋·온스크린이 실제 배경·자막 위에 얹힌 정지판은 따로 본다. 6편 시안 3판의 결함 8건(원반이 고리로 읽힘·궤도가 꽃처럼·b01 헤드라인 교차·격자 위 글자 안 읽힘)은 전부 여기서 잡혔고 v1 이후 사용자 지적은 0 이었다. (6편)
- **정지에서 통과한 부품이 영상에서 죽는다** — 시안은 `textAnim:false` 라 0프레임 애니 경로를 안 탄다. `fill_sec: 0.01` → `Math.round(0.3)=0` → `interpolate([0,0])` 크래시(프레임 398). 부품의 프레임 길이는 `durF = max(1, round(sec*fps))` 로. (6편)

### 6 마감·최종 검토

- 최종 검토 12건 반영: placeholder 최종 미표시, 자막 반투명 밴드, 카운터=자막 줄 대체, 텍스트 비트는 직전 배경 dim 유지, 다이어그램 제거(과밀), 증거 카드 구절 주인공, 엔드카드 4s (1편)

1. **1초 전수 프레임**(77장) + **이음새 정밀**(경계 ±0.3s·±0.07s) — 씬 내 도해 교대 공백·자막 겹침.
2. **원해상 에지 검사**: 인셋·도해 공존 비트를 원본 해상도 + 인셋 경계선(x px) 오버레이로 — 축소 시트는 15px 급 겹침을 가리고, layout:43 은 풀프레임 씬(MC·코드 도해) 내부 px 를 못 본다. 도해가 실사 피사체를 가로지르면 '레이어링'이 아니라 겹침.

4. **오디오 끝단·SFX**: 마지막 1초 RMS(드론 길이+BGM 페이드 겹침 무음 함정) · SFX 시각창 실측(스파이크 불명이면 사용자 청취 항목) · **0.4s 미만 창에 ebur128 통합 금지(−70 오류) → volumedetect**.

- 대조 왕복 부탁 A~Q(문자 통번호), facts 개정 3건(#13 커먼즈 실사 허용·#23 범주 허용·#19 냉가스) — 사용자 지시로 표현 규칙을 여는 개정은 "(YYYY-MM-DD 사용자 지시)" 꼬리표로 input 이 반영.

- **BGM 레벨은 「발화 틈 RMS −26 dB 안팎」이 기준값이다**(4편 사용자 승인, 5·6편 재현). 발화 중은 duck 만큼 더 아래(−6~−8 → −32~−34). 옛 문구 「발화 중 내레이션 −12~−15 dB 아래」는 duck −8 과 양립하지 않아 폐기 — [audio.schema 4c](../../../../docs/specs/audio.schema.md). 원곡 인트로가 본체보다 5~9 dB 조용하면 훅 첫 0.4초가 「사실상 무음」이 된다 → `start_offset` 을 본체 시작으로(6편 0→10s). (5·6편)
- **엔드카드 크레딧은 명령이 만든다** — `credits.cmd.txt` 에 `--extra` 까지 적어 두고 `--check` 도 같은 인자로. 기사 줄은 `pilot.json.article.byline` 에서 자동. CC BY-**SA** 는 "CC BY" 로 줄이지 않는다(share-alike 가 사라진다 — 6편 ESA 상상도). (6편)

### 운영 — 워크트리·미디어·git

- **Studio·렌더는 반드시 워크트리에서.** 메인 체크아웃엔 편 미디어가 없다(`public/` git 제외) → "이미지가 안 뜬다". 커밋 뒤 셸 cwd 가 리셋되므로 매번 `cd` 를 명시한다.
- **미디어 복구는 둘로 나뉜다** — `restore:media` = `ext`·`video`(shots 의 `origin_path` 파생) / `sync` = 클라이언트 사진·데이터. **`sync` 는 정본 경로**(`~/Projects/shortform-news-input/work/<id>`)를 줘야 한다. 워크트리 경로를 주면 조용히 `(none)`.
- **워크트리에서 과거 커밋과 대조할 때 `git checkout HEAD -- <path>` 로 되돌리지 않는다.** HEAD 가 그 변경 이전이면 복원이 아니라 **삭제**다(5편에서 3D 가 이렇게 사라진 채 커밋됐다). 임시 커밋이나 `git stash push -m <태그>` 를 쓴다.
- **머지해도 `out/` 은 따라오지 않는다 — 워크트리를 지우기 전에 정본으로 옮긴다.** `out/` 은 gitignore 라 **체크아웃마다 따로**이고 `git merge` 는 추적 파일만 옮긴다. 5편은 머지 직후 납품본이 **워크트리에만** 있었다(882MB) — 그 상태에서 `git worktree remove` 했으면 `deliver/v4/` 가 사라졌다.
  ```bash
  cp -R .claude/worktrees/<id>/out/pilots/<id> out/pilots/     # 머지 뒤 첫 순서
  npm run out:audit                                            # 정본에서 — MISS 0 이어야 한다
  ```
  **검증은 이미 있었다** — `out:audit` 은 대장이 가리키는 파일이 없으면 `MISS` 를 낸다. 절차에 없었을 뿐이다. 머지 완료 판정에 `정본 out:audit MISS 0` 을 넣는다. md5 는 위치가 바뀌어도 그대로라 이전 뒤 재검증으로 무결성을 증명한다.
- **MC 씬은 `tools/motion-canvas/` 라 워크트리 밖(정본)에 있다** — 편 작업 중 고쳤으면 워크트리 브랜치로 옮겨 커밋한다. 알파 클립은 git 제외라 **씬이 정본**인데, 5편은 씬 3개가 미커밋이라 클립을 잃으면 복구 불가였다.

input이 되돌린 판단 5: svs5258 배정(계획 수치 옆 현재 물체) · 즈나미야 권리 · 태양 파일 확장자(.jpg가 WebM) · b03 ISS 구간 2초(오로라) · "무명의 하늘" 요구. output이 되돌린 것 2: G1 생성(제품 규칙) · 스톡 뭉뚱그리기(b21·b22 A△). 사용자가 되돌린 것 3: G1 채택 · 인셋 위주 배정 · 스톡 유지 판정.
