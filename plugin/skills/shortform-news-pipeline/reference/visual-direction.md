# 개념 장면의 화면 설계

이미지·일러스트·인용·표·그래프·도해를 구상할 때 [시각 표현·스타일·합성 안내](visual-expression.md)를 함께 읽는다. 이해·몰입·시각적 재미를 위해 자유롭게 조합하며 사용 빈도나 장면별 배치를 고정하지 않는다.

## 관계부터 정한다

전체 이야기에서 이 구간이 맡는 일을 먼저 읽고, 시청자가 볼 대상과 관계를 정한다. 장면 안의 설명력과 장면 사이의 흐름을 함께 설계한다.

| 설명 관계 | 우선 표현 |
|---|---|
| 위치·대상·현장 | 공식 영상·사진을 전체 화면으로, 핵심 피사체가 남는 크롭 |
| 크기·속도·면적 비교 | 같은 중심·척도·기준 대상을 유지하는 도해 |
| 과정·순서 | 하나의 대상을 유지하며 상태를 순서대로 바꾸는 도해/영상 |
| 관측 결과·인용 | 실제 자료를 주인공으로, 필요한 출처·상태만 표시 |
| 보이지 않는 개념·정서 | 오인되지 않는 은유, 톤 영상, 또는 자막에 맡김 |

이 표는 후보를 떠올리는 출발점이다. 실제 자료의 움직임·질감·규모감이 설명과 몰입에 주는 효과, 도해가 관계를 드러내는 효과를 함께 판단한다. 긴 구간이 같은 자료나 도해에 머물 때는 시청자의 이해가 계속 진전되는지 본다. 적합한 수단과 길이를 선택하며 실사·도해 비율이나 의무 교차 패턴은 두지 않는다.

도구는 Higgsfield 이미지·생성 모션, React/SVG, 3D, Motion Canvas, 실사 중 표현 정확도·시청 경험·수정 비용으로 고른다. 자연 현상을 부정확한 기하 도형으로 흉내 내지 않는다. 완성 도해 레이아웃은 주제마다 다시 설계하고 축·격자·연결점·비교 막대·등장/퇴장 같은 작은 기능만 공통화한다.

## 위계와 모바일 정보량

한 순간에 먼저 읽어야 할 것을 `mobile.focal_priority` 순서로 적는다. 1/3 크기에서 첫째 대상과 관계가 즉시 보이지 않으면 크기·대비·배치를 다시 만든다.

- 장면 중심에는 핵심 대상 하나를 크게 둔다.
- 라벨 예산은 개념별 주목 대상과 관계에 맞춰 정한다. 템플릿의 2~3개는 출발값이며 전역 상한이 아니다. 조건과 값이 함께 읽히는지와 실제 모바일 정보량을 검수한다.
- 새 정보는 발화 순서대로 더하고, 읽은 설명은 다음 개념 전에 정리한다.
- 자막 시각 스타일은 `config/production-profile.json`의 공통 기본값이다. 새 편의 `visual-system.production_profile`은 `produce start`가 연결하고 중앙 자막 런타임이 컴파일된 프로필을 적용한다. 사용자가 스타일 변경을 요청한 경우에만 별도로 다루며, 편별 문서에 굵기·좌표를 중복 기입하지 않는다.
- 신규 공통 자막은 한 번에 한 줄이다. 긴 문장은 `narration.json`의 `captions[]`에 실제 단어 시각을 사용해 의미 단위로 나눈다. `caption_text`의 강제 줄바꿈, 자동 줄바꿈, 글자 축소·잘림으로 맞추지 않는다. 제작자는 분절·강조·발화 타이밍과 읽을 시간을 판단하고 핵심 대상과의 겹침을 확인한다. 컴파일이 줄바꿈·구간 겹침을, 프루프·렌더가 실제 폰트와 강조 굵기의 한 줄 폭을 검사한다. 폭 오류의 구간을 다시 나눈 뒤 시안에서 읽힘을 확인한다.
- 상단 고정 제목, 제작 과정 문구, “설명용 개념도” 같은 주석은 쓰지 않는다.
- 기사 시점·가설·시뮬레이션·향후 조건처럼 의미를 바꾸는 문구는 해당 값과 동시에 보이게 한다.

## 전체 화면

배경 영상과 이미지는 1080×1920을 채운다. 그 위에 합성하는 컷아웃·일러스트·문서 발췌 등 개별 자산은 장면에 맞는 크기와 위치로 배치한다. 세로 원본이 아니어도 핵심 피사체가 남도록 cover crop과 object position을 설계한다. 여백이 꼭 필요한 비교·문서·다중 패널은 `layout_exception`에 이유를 적고, 남는 공간은 장식 문구로 채우지 않는다.

크롭은 중간 프레임 하나로 정하지 않는다. 클립당 4~6장과 실제 연속 재생에서 대상이 프레임을 벗어나지 않는지 본다. 글자와 세부 표식은 원해상 크롭에서 판정한다.

## 프루프

개념마다 다음을 남긴다.

1. 첫 상태
2. 핵심 요소가 들어오는 중간
3. 설명이 완성된 정착 상태
4. 다음 상태 직전
5. 1/3 모바일 표본

정지 화면은 위계와 관계를, 연속 구간은 속도와 인과를 판정한다. 자동 검사는 요소 수와 시점 계약을 확인하며 화면의 설득력은 독립 검수자가 실물을 본다.
