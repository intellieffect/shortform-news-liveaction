# 생성 커버 예시 — 고정 제목과 장면 설계

현재 기본값은 [고정 제목 스타일](cover-style.md)이다. 아래 이미지는 2026-09-07 사용자가 채택한 제목 위치·크기·강조 방식을 유지하면서 부수 텍스트를 제거한 시안이다. 다음 편에도 제목 스타일은 유지하며 장면은 소재에 맞게 설계한다. 예시는 사실 자료가 아니다.

| 예시 이미지 | 장면의 역할 | 다른 소재에 적용할 판단 |
|---|---|---|
| [커피와 태양](../assets/cover-style/solar-swirl.png) | 커피 속 크림과 태양 표면을 나란히 놓아 낯선 무늬를 익숙한 경험과 연결한다 | 비유를 쓴 문구라면 이미지에서 그 비교를 보여준다 |
| [뒤집힌 은하](../assets/cover-style/disc-flip.png) | 은하 원반 방향의 차이와 작은 화살표로 변화를 보여준다 | 전후 차이를 장면 자체로 이해하게 한다. '이전/이후' 라벨과 작은 해설을 추가하지 않는다 |
| [우주 택배](../assets/cover-style/starfall.png) | 택배 상자와 지구를 가로지르는 경로로 운송의 규모와 낯섦을 보여준다 | 추상적인 구상을 익숙한 물건·행동으로 구체화하고 물음표 등 제목의 불확실성을 보존한다 |

세 이미지 모두 941×1672 PNG이며 플러그인만 배포받아도 열어볼 수 있다. 기본 스타일 입력은 커피·태양 한 장이다. 나머지 둘은 적용 예시이며 세 장을 의무적으로 입력하지 않는다. 이 기준 이미지들에는 로고 영역이 없으므로 새 제작에는 [고정 스타일](cover-style.md)의 로고 영역을 별도로 적용한다. 기준 PNG는 내부 참고용이며 사용자 제출 화면에는 새 후보만 보여준다.

커피·태양의 태양 영역은 이전 관측 자료 참고 시안을 바탕으로 생성한 재구성이고 원본 관측 데이터가 아니다. 이전 참고 자료의 출처는 NSF/NSO/AURA/MPS다. 은하 원반 변화와 우주 운송 경로는 개념 표현이다. 이러한 성격과 출처는 제작 기록에 남기며 이미지 안의 주석으로 다시 넣지 않는다. 참조 입력 역할은 `style`이며 기존 편의 문구·소재를 새 편에 그대로 복제하지 않는다.

## 전달력 보존·과장 조절의 예

[태양 소용돌이 수정안](../assets/cover-direction/solar-swirl-balanced.png)은 사용자가 요청한 ‘기존 시안의 전달력·표현력 + 실물의 비현실성만 축소’ 방향을 보여준다. 관측 원본이나 모든 소재의 고정 구도는 아니다.

- **유지한 장점:** 돋보기로 작은 경계를 크게 읽히게 하는 발견의 비유, 주목 대상의 크기, 원근과 빛, 두 줄 제목의 위계.
- **조절한 부분:** 솟은 화염·파도처럼 보이던 흐름을 표면에 붙은 형태로 낮추고 과도한 발광을 줄였다. 이미지를 평평한 자료 병치로 바꾸지 않았다.
- **다른 소재에 옮길 판단:** 효과적인 관계·구도를 먼저 보존하고, 실물을 다른 현상으로 읽히게 하는 형태·물성만 고친다. 컵·돋보기·태양·주황색을 다음 편에 자동 복제하지 않는다.

이 이미지는 생성된 설명용 삽화이며 크기·비례는 비정량이다. NSF/NSO/AURA/MPS 관측 자료(CC BY 4.0)를 질감 참조로 사용했다. 예시를 고칠 때는 [커버 판단](cover.md#표현력과-실물의-신뢰성을-함께-설계한다)의 원칙으로 새 소재에서 다시 검토한다. 제목 기준 PNG는 계속 [고정 스타일](cover-style.md)의 것을 사용하며 이 예시를 매번 추가 입력할 필요는 없다.

이전 2026-09-06 생성 예시는 `assets/cover-examples/`에 역사 자료로 보존한다. 그 이미지의 보조 문구·민트색 제목·가변 배치는 현재의 생성 기준으로 사용하지 않는다.
