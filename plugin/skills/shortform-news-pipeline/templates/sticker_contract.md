# 스티커 계약 — <편>

편마다 **한 번** 쓰고 그 편의 모든 스티커가 따른다. 씬 계약(`mc_spec.md`)과 같은 자리다 —
**구현이 계약을 고치지 못하게 하는 것**이 값이고, 프롬프트보다 **먼저** 쓴다(게이트 E9).

스티커 = 배경 위에 얹는 생성 오브젝트. 3단 판정 **tier 3a(은유)** 의 자리다.
**인셋은 실사를 창으로, 스티커는 생성물을 실루엣으로.** 사실을 나르지 않는다 — 수치가 붙으면 도해로 간다.

> **§1~§5 는 고정값이다. 편이 채우는 것은 §6 목록뿐이다.**

## 0. 무엇을 뽑나 — 내레이션이 이미 말한 비유

**원고가 만든 은유를 화면이 받는다. 우리가 은유를 만들지 않는다.**
문장이 「**~처럼 · ~ 모양 · ~ 크기**」로 비유를 말하는 자리가 스티커의 자리다.

| 편 | 자막 | 스티커 |
|---|---|---|
| 5편 b07 | 태양 표면은 **끓는 냄비 속 기포**처럼 | 냄비 |
| 5편 b12 | **커피에 크림**을 부을 때 보이는 그 무늬 | 커피잔 |
| 3편 b05 | **소형 냉장고 크기**지만 | 냉장고 |
| 4편 b10 | 납작한 원반, **팬케이크 모양** | 팬케이크 |

이 규칙이 둘을 동시에 지킨다 — 비유 대상이 **이미 자막에 있으므로** §10(내레이션에 없는 낱말 금지)에 안 걸리고,
**근거 없는 은유**(우리가 지어낸 저울·시소 따위)가 원천적으로 안 나온다.

### 5단 필터

| 물음 | 아니면 |
|---|---|
| 1. 실사가 있나 | 배경·인셋 |
| 2. 자와 컴퍼스로 그려지나(수치·비율·구조) | 도해 |
| 3. 고유명사·실존 시설·인물·실물 디자인인가 | **금지** — 자막 |
| 4. **형상이 있는 보통명사인가** | **스티커** ✅ |
| 5. 형상 없는 추상인가 | 자막 |

**4번을 빠뜨리면 이상한 것을 뽑는다.** 「윔프」는 tier 3a 이지만 **정의상 형상이 없어** 스티커도 못 된다 —
8편 b09 가 생성을 3회 태운 이유가 여기 있고 **8편은 스티커 후보가 0**이다. 3a 라고 다 스티커가 되지 않는다.

## 1. 프롬프트 — **문형 고정**

대상 이름만 갈아 끼운다. 형태·양식·배경을 따로 지정하지 않는다.

```
A die-cut sticker of <대상>. The sticker has a thick white die-cut border that
follows the object's own outline, slight glossy sticker surface. The sticker
lies flat, centered, on a plain flat light grey surface.
No text, no letters, no watermark, no other stickers, no hands.
```

**이 문형이 형태를 만든다.** 실측 — 냄비는 손잡이 두 개까지, 커피잔은 손잡이 구멍까지 테두리가 돌았고,
로켓은 길쭉한 실루엣, 은하는 울퉁불퉁한 유기적 윤곽이 나왔다. **모양을 지정할 필요가 없다.**

| 고정값 | |
|---|---|
| 모델 | `nano_banana_pro` (Higgsfield) |
| 규격 | 1:1 · 2048px |
| 배경 | **연회색 평면** — 키 색(초록)을 쓰지 않는다 |
| 테두리 | **흰색**, 대상 윤곽을 따라감 |
| 양식 | **실사 사진.** 양식을 지정하지 않는다(§2) |

**주의 — 흰 대상은 흰 테두리에 먹힌다.** 로켓(흰 기체)이 그랬다. 대상 색을 프롬프트에 적거나 이 편만 테두리 색을 바꾼다.

## 2. 양식을 지정하지 않는 이유

판화·아이콘·에나멜 핀·종이 콜라주를 시험했는데 **전부 양식이 스스로를 주장했다** —
스티커는 낱말을 알아보게 하는 보조인데 자기가 볼거리가 된다. 5편 냄비·커피가 괜찮았던 이유는 **평범해서**다.

관측 대상도 같은 문형으로 간다 — **흰 테두리가 경계를 만들어 주므로** 은하·성운처럼 경계가 없는 것도 된다.

금지는 **평면 2색 벡터** 하나 — 대상 인지에 실패한다(블랙홀이 **파란 도넛**이 됐다).

## 3. 후처리 — `npm run sticker:cut`

```bash
npm run sticker:cut -- <생성 png…> --out news/<id>/02_production/external_assets/sticker
```

배경이 단색 평면이고 흰 테두리가 닫힌 경계라 **가장자리 flood fill 하나**로 떨어진다.
크로마키·알파 이진화·구멍 메우기·연결 성분 검사·기하 마스크가 **전부 불필요**하다(전 시도에서 다 실패했다).

## 4. 배치

| 항목 | 값 |
|---|---|
| 원본 | `02_production/external_assets/sticker/<id>_v<N>.png` (알파) |
| 파생 | `public/pilots/<id>/sticker/` (`npm run sync`) |
| 화면 크기 | `size` S/M/L → 존에서 파생. **px 를 부품에 직접 적지 않는다**(R1-05) |
| 위치 | `anchor` — 존 이름. **배경 실물 위치에 맞추지 않는다**(맞춘 척하면 거짓 표시) |
| 등장 | `in` = **낱말 시각**(`beats[].words` 파생) |

## 5. 금지와 검수

`facts.md` §AI 금지를 그대로 상속한다.

- **고유명사·실존 시설·실존 인물·실물 디자인·기업 로고·특정 도시** — 실사가 권리로 막혔다고 스티커로 우회하지 않는다
