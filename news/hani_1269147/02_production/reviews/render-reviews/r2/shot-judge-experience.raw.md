## 전체에서 읽힌 이야기 (표본 기준)

암석 행성 하나(같은 상상도가 처음·중간·끝에 반복)에서 푸른 빛방울이 위로 흩어진다 → 이름(LHS 1140b, 49광년·암석형) → 생명 조건 세 가지 체크리스트(땅·온도 체크, 대기 빈칸) + 골디락스 궤도 도해 → 붉은 왜성이 복사를 쏟아 대기를 벗긴다 → TRAPPIST-1 일곱 행성에서 대기 흔적 못 찾음 → 지평선 클로즈업: 푸른 점은 위로, 주황 점은 아래 띠로 갈라짐(수소·헬륨 ↑ / 질소 ↓, "컴퓨터 모델 예측·관측 아님") → 2024 마젤란 망원경 실사 → 붉은 별 앞을 행성이 지남(통과) + 무지개 띠에 어두운 선 = 헬륨 흡수선 → 같은 행성으로 복귀 "대기 확인·처음", 체크리스트 세 칸 체크 → 무거운 기체·온실효과 조건문 + 액체 바다 가능성 → 30억 년 유지 가능성 → 2025년 관측 헬륨 신호 없음, 방출량 변동 해석 → 크레딧 + 화면 축소 종결.

도입(새는 대기라는 역설)·진전(조건 → 적색왜성 문제 → 모델 → 관측)·결말(의미·단서)이 표본만으로도 순서대로 읽힌다. 관심이 가장 선명한 지점은 흡수선이 띠에 나타나는 구간, 이해가 멈춘 지점은 60~73초의 주황 곡선.
