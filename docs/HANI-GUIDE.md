# 사용 안내 — 요청부터 확정본까지

이 저장소는 `main` 하나에서 편을 쌓는다. 워크트리·브랜치·병합·push는 쓰지 않는다. 커밋은 제작 절차가 확정 시점에 자동으로 한다.

## 요청

| 하고 싶은 것 | Claude에게 이렇게 말한다 | 일어나는 일 |
|---|---|---|
| 새 편 | `<기사 URL> 이 기사로 숏폼 만들어줘` | 기사 하나에 편 하나가 생긴다. 한겨레 기사는 편 id가 `hani_<기사번호>`다 |
| 수정 | `<기사 URL> 편에서 ○○ 고쳐줘` | 같은 편을 이어서 고친다. 새 편(`_v2` 등)을 만들지 않는다 |
| 되돌리기 | `<기사 URL> 편을 v1로 돌려줘` | v1 영상을 새 버전으로 다시 확정한다. 이력은 지우지 않는다 |

URL 없이 “아까 거 고쳐줘”라고 하면 Claude가 어느 편인지 한 번 확인한다.

## 확정본

- 편이 완성되거나 수정이 끝날 때마다 새 버전(v1, v2, …)이 생기고 **가장 마지막 버전이 확정본**이다.
- 확정할 때 대본·데이터·장면 코드가 `main`에 자동 커밋된다(메시지 `편 <id> vN 확정`). 커밋 뒤 `git status`는 비어 있다.
- 영상 파일은 커밋하지 않는다. `out/pilots/<id>/deliver/vN/`에 있고, 해시만 `pilots/<id>/pilot.json`에 기록된다.

## 완성 영상 보기

`out/videos.html`을 브라우저로 연다. 확정할 때마다 자동으로 다시 만들어진다. 직접 다시 만들려면 `npm run videos`.

- 편마다 확정본 하나가 `확정본 vN` 표시와 함께 보인다.
- 이전 판은 다운로드 메뉴의 «이전 판»에서 받는다.
- 아직 확정본이 없는 편은 목록 아래 «제작 중»에 나온다.

## 처음 한 번

```console
git config user.name "이름"
git config user.email "메일"
```

이름이 없으면 자동 커밋이 멈추고 이 안내를 보여 준다.

## 백업

영상 파일은 이 컴퓨터의 `out/` 폴더에만 있다. `out/pilots/*/deliver/` 폴더를 주기적으로 다른 곳에 복사해 둔다.
