## 수정·재렌더 범위

news의 원문·제작 데이터·렌더에 사용한 자산, pilots의 구성, src/editorial/episodes의 장면 코드와 폰트·로고를 포함한다. sync로 public/pilots를 복원할 수 있다. 실제 사용하지 않은 후보·계정 조회·내부 세션 로그·이전 시안은 제외했다. 썸네일은 최종 합성본만 수록하며 재생성 원본/중간 편집 계보는 포함하지 않는다.

원래 작업 환경의 run.json 실행 영수증은 전달하지 않는다. 수정 시 이 환경의 새 실행·검수 기록을 만들며, resume이 기존 단계의 실행 영수증을 미기록으로 표시하는 것은 정상이다. 과거 통과 상태를 새 환경에서 실행한 것으로 채우지 않는다. validation-scope.md가 언급하는 일부 내부 로그는 로컬 원본 보관 범위이며 수록 파일이 아니다.
