# 한겨레 숏폼 제작 — 활용 매뉴얼

| 문서 버전 | 대상 설치본 | 작성일 | 상태 |
|---|---|---|---|
| v0.10 | 숏폼 뉴스 제작 플러그인 1.5.1 | 2026-09-30 | Windows 설치본 검증 전 초안 |

이 매뉴얼은 Claude 데스크톱 앱의 **Code 탭**에서 말로 요청하는 방법을 모았습니다. 명령어는 몰라도 됩니다. 각 장은 **이럴 때 → 이렇게 입력하세요 → 이렇게 됩니다 → 주의** 순서입니다. 회색 상자의 문장을 복사해 `< >` 부분만 바꿔 넣으세요. 화살표(→)는 차례로 누르는 순서입니다.

---

## 0. 시작 전에

**요청 화면 열기 — 매번 이 순서로**

1. **Claude 앱**을 엽니다.
2. 창 위쪽 탭에서 **Code**를 누릅니다. (Chat·Cowork 탭에서는 제작 도구가 동작하지 않습니다.)
3. 입력창 아래의 실행 위치에서 **Local**을 고릅니다. (Cloud를 고르면 이 컴퓨터의 제작 폴더를 쓰지 못합니다.)
4. 입력창 아래의 폴더 선택에서 숏폼 제작 폴더 **shortform-news-liveaction**을 고릅니다. 목록에 없으면 폴더 선택 → 다른 폴더 열기 → 설치 때 받은 `shortform-news-liveaction` 폴더를 고릅니다.
5. 폴더 이름 옆에 **worktree(작업 복사본) 선택이 있으면 켜지 않습니다.** 영상은 제작 폴더에서 바로 만들어야 확정·목록에 쌓입니다.
6. 입력창에 요청을 적고 **Enter**를 누릅니다.

진행 중 "허용할까요?" 같은 확인 창이 뜨면 내용을 읽고 **허용**을 누릅니다. 이미 연 대화에서 이어서 요청할 때는 왼쪽 목록에서 그 대화를 눌러 이어 씁니다.

**꼭 지킬 세 가지**

1. **한 번에 한 편**씩 요청합니다. 한 편이 끝나거나 멈춘 뒤 다음 기사를 요청하세요.
2. **같은 기사 = 같은 영상**입니다. 이미 만든 기사 주소를 다시 넣으면 새로 만들지 않고 "이미 있는 영상"이라고 알려 준 뒤 그 영상을 이어서 고칩니다.
3. **이번에 적은 요청이 기본 설정보다 우선**합니다. "45초로", "음성 전에 멈춰줘"처럼 적은 조건은 기본 제작 방식보다 먼저 적용됩니다.

**편을 가리키는 법**: 고칠 때는 문장 앞에 **기사 주소(URL)**를 붙이세요. 주소 없이 "아까 거 고쳐줘"라고 하면 어느 영상인지 한 번 되묻습니다.

**결과를 보는 곳**

| 보고 싶은 것 | 보는 곳 |
|---|---|
| 제작 중 안내·구성안·질문 | Code 탭 대화 화면 |
| 완성 영상·이전 판 재생·내려받기 | 완성 영상 목록 — 여는 법은 8장 |

## 1. 새 영상 만들기

**이럴 때** — 기사 하나로 새 숏폼을 만들 때.

**이렇게 입력하세요**

```
<기사 URL> 이 기사로 숏폼 만들어줘
```

```
<기사 URL> 이 기사로 숏폼 만들어줘. 끝 크레딧 시간은 빼고 본문만 60초 안팎으로 해줘
```

**이렇게 됩니다**

- 기본 제작 지시(60~90초, 일반 시청자 대상)가 자동으로 적용됩니다. 긴 지시문을 붙여 넣을 필요가 없습니다.
- 기사 확인 → 자료 수집 → 원고 → 음성 → 화면 → 검수 → 완성본까지 **중간에 묻지 않고** 진행합니다. 썸네일 후보도 함께 만듭니다.
- 끝나면 대화 화면에 완성 영상과 중요한 선택·남은 한계가 정리되고, 검수를 통과한 영상은 자동으로 확정되어 완성 영상 목록에 올라갑니다(8장).
- 10장의 기본 항목(자막 위치·끝 크레딧·후킹 등)은 요청하지 않아도 들어갑니다.

**주의**

- 분량을 "본문만 ○초"라고 적으면 끝 크레딧 시간은 따로 더해집니다. "전체 ○초"라고 적으면 크레딧까지 포함한 길이입니다.
- 한 편 제작에는 시간이 걸리고, 음성·이미지·영상 생성 크레딧이 사용됩니다.

## 2. 음성 만들기 전에 구성안 확인하고 멈추기

**이럴 때** — 음성을 만들기 전에 구성과 원고, 후킹 문구를 먼저 보고 싶을 때.

**이렇게 입력하세요**

```
<기사 URL> 이 기사로 숏폼 만들어줘. 음성 만들기 전에 구성안·원고·후킹 문구를 보여주고 멈춰줘
```

멈춘 뒤 답하는 법:

```
진행해줘
```

```
후킹 문구를 '<새 문구>'로 바꾸고 진행해줘
```

```
원고 세 번째 문장을 '<새 문장>'으로 고치고 다시 보여줘
```

**이렇게 됩니다**

- 기사 확인·자료 수집·원고 작성까지 한 뒤, 음성을 만들기 **직전에** 멈추고 대화 화면에 아래를 보여 줍니다.

| 보여 주는 것 | 내용 |
|---|---|
| 구성안 | 구간 순서, 구간마다 맡는 일과 주요 화면 한 줄씩 |
| 원고 | 낭독 원고 전문 (첫 문장 = 후킹 문장 표시) |
| 후킹 문구 | 화면에 크게 뜰 문구, 줄 구성, 밑줄 위치 |
| 배경음악 후보 | 이 편에 쓸 곡 후보 |
| 예상 분량 | 예상 영상 길이 |

- "진행해줘"라고 하면 그대로 음성부터 끝까지 진행합니다.
- 고칠 내용을 말하면 반영하고 진행합니다. "다시 보여줘"를 붙이면 고친 결과를 보여 주고 다시 멈춥니다.

**주의**

- 멈춤 조건을 적지 않으면 멈추지 않고 끝까지 만듭니다(기본 동작).
- 이 기능은 기사로 구성안을 **따로 자동 생성하는 기능이 아니라**, 평소 제작 흐름을 음성 직전에 잠시 세우는 방식입니다.
- 멈춘 상태에서 다른 기사를 요청하지 마세요. 먼저 "진행해줘" 또는 수정 답변으로 이 편을 이어 가세요.

## 3. 후킹 문구 바꾸기

**이럴 때** — 영상 첫머리에 크게 뜨는 문구(노란 밑줄)를 바꾸고 싶을 때.

두 가지 경우가 있습니다.

| | 화면 문구만 | 첫 문장까지 |
|---|---|---|
| 바뀌는 것 | 화면에 크게 뜨는 문구 | 내레이션 첫 문장 + 화면 문구 |
| 음성 | 그대로 | **다시 만듦** (크레딧 사용) |
| 언제 | 첫 문장은 좋은데 화면 문구만 짧게·세게 | 첫 문장 자체를 바꾸고 싶을 때 |

**이렇게 입력하세요**

```
<기사 URL> 편 후킹 화면 문구를 '<새 문구>'로 바꿔줘. 음성은 그대로 둬
```

```
<기사 URL> 편 첫 문장을 '<새 문장>'으로 바꾸고 후킹 문구도 맞춰줘
```

**이렇게 됩니다**

- 화면 문구만 바꾸면 음성과 일반 자막은 그대로이고 첫머리 문구만 바뀝니다.
- 첫 문장까지 바꾸면 음성을 새로 만들고 자막·화면 타이밍도 다시 맞춥니다.
- 고친 뒤 확정하면 새 버전으로 쌓입니다(8장).

**주의**

- 화면 문구는 첫 문장과 **같은 핵심**이어야 합니다. 새 문구가 첫 문장과 뜻이 어긋나면 첫 문장도 맞춰 고쳐야 하고, 그러면 음성을 다시 만듭니다.
- 후킹은 영상 초반에 **한 번만** 등장합니다. 중간에 다시 띄우는 요청은 기본 규칙과 맞지 않습니다.
- 바꿀 수 있는 것은 **문구**입니다. 글꼴·밑줄 색·그림자 같은 디자인은 모든 영상에 공통이라 이 요청으로 바뀌지 않습니다.

## 4. 장면·컷·카메라·도식을 이 편에만 요청하기

**이럴 때** — 특정 장면이 길게 머물거나, 움직임·도식을 더하고 싶을 때. **그 영상 한 편에만** 적용됩니다.

**이렇게 입력하세요**

```
<기사 URL> 편 보름달 장면이 너무 길어. 관련 사진 컷을 하나 더 넣어 두 컷으로 나눠줘
```

```
<기사 URL> 편 행성 장면에 천천히 다가가는 카메라 움직임(줌인)을 넣어줘
```

```
<기사 URL> 편에서 두 수치를 막대 비교 도식으로 보여줘
```

**이렇게 됩니다**

- 해당 장면만 고치고 나머지는 유지합니다. 음성은 원고를 바꾸지 않는 한 그대로입니다.
- 고친 뒤 다시 검수하고, 결과를 대화 화면에 보여 줍니다.

**주의**

- 장면이 어디인지 **기사 속 대상이나 대략의 시간**(예: "0:40쯤 보름달 장면")으로 알려 주면 정확합니다.
- 추가 컷은 기사와 관련된 실제 자료나 상상도로 넣습니다. 알맞은 자료가 없으면 그 사실을 알려 줍니다.
- "모든 장면 4초 이하", "모든 문장 2컷", "카메라 움직임 기본 적용", 수치 카운트업·팝업 모션·효과음 자동 생성처럼 **모든 영상에 자동 적용**하는 기능은 지금 없습니다. 지난 회신대로 범위·일정을 별도로 논의하는 항목이며, 그 전까지는 이 장처럼 편마다 요청하세요.
- 영상 위쪽에 고정 제목(헤드라인바)을 넣는 요청은 기본 제작 지시와 맞지 않아 편마다 요청해도 넣지 않습니다.

## 5. 배경음악 — 공용 음원 폴더

한겨레가 가진 음원을 **공용 음원 폴더**에 넣어 두면 여러 영상에서 다시 쓸 수 있습니다. 폴더에 파일을 직접 복사하지 말고 아래처럼 **Claude에게 요청**하세요. 출처·추가일이 자동으로 기록됩니다.

**넣기 전에 — 파일 이름을 정하세요.** 파일 이름(확장자 `.mp3` 등 제외)이 **끝 크레딧 "음악" 줄에 그대로** 들어갑니다. 원하는 표기로 파일 이름을 바꾼 뒤 넣으세요. 예: 파일 이름이 `Music - 새벽 공기 by 홍길동.mp3`이면 끝 크레딧에 `Music - 새벽 공기 by 홍길동`이 나옵니다. 파일 이름에 `< > : " / \ | ? *` 기호는 쓸 수 없습니다(`_`로 바뀝니다).

**이럴 때 ① — 음원을 공용 폴더에 넣을 때**

1. 음원 파일을 Code 탭 **입력창에 끌어다 놓습니다**. (또는 입력창 옆 **+** → 파일 첨부 → 음원 파일 선택. 인터넷 주소면 주소를 그대로 붙여 넣습니다.)
2. 이어서 아래 문장을 적고 Enter를 누릅니다.

```
이 음원 공용 음원 폴더에 넣어줘
```

**이럴 때 ② — 들어 있는 음원을 볼 때**

```
공용 음원 목록 보여줘
```

**이럴 때 ③ — 이 편에 쓸 때**

```
<기사 URL> 편 배경음악으로 공용 음원 폴더의 '<파일 이름>' 써줘
```

**이럴 때 ④ — 음량을 조절할 때**

```
<기사 URL> 편 배경음악을 조금 더 작게 해줘
```

**이렇게 됩니다**

- 넣기: 라이선스·크레딧 문구를 되묻지 않고 바로 넣습니다. 목록에 출처(파일/주소)·추가일이 기록되고 자동 저장됩니다. 대화 화면에 "끝 크레딧 음악 줄: <파일 이름>"이 표시됩니다. 같은 파일을 두 번 넣으면 이미 있다고 알려 줍니다.
- 목록: 파일 이름(= 끝 크레딧 음악 줄)·출처·추가일·파일 있음 여부가 표로 나옵니다.
- 이 편에 쓰기: 음원이 그 영상에 연결되고, 권리 기록과 끝 크레딧 "음악" 줄(파일 이름)이 자동으로 채워집니다. 끝 크레딧 표시 방식은 7장.
- 새 영상을 만들 때도 Claude가 **공용 폴더를 먼저** 살펴보고 맞는 곡이 있으면 후보로 씁니다.

**주의**

- **음원의 라이선스·사용 범위 확인은 한겨레가 맡습니다.** 공용 폴더에 넣은 음원은 사용해도 되는 것으로 보고 씁니다.
- 끝 크레딧 표기를 바꾸고 싶으면 파일 이름을 바꿔 **다시 넣고**, 그 파일 이름으로 ③을 다시 요청하세요.
- 파일 이름 일부만 적어서 여러 곡에 맞으면 어느 곡인지 되묻습니다.
- 음원 파일은 **이 컴퓨터에만** 저장됩니다. 백업은 8장.

## 6. 발음·숫자·자막 끊김 고치기

**이럴 때** — 숫자를 잘못 읽거나, 자막이 어색한 곳에서 끊길 때.

**이렇게 입력하세요**

```
<기사 URL> 편에서 '6시'를 '여섯 시'로 읽게 고쳐줘
```

```
<기사 URL> 편 자막에서 '국제 달 관측의 날'이 둘로 끊겼어. 음성은 그대로 두고 자막만 다시 나눠줘
```

**이렇게 됩니다**

| 요청 | 화면 자막 | 음성 |
|---|---|---|
| 읽는 법 고치기 | "6시" 그대로 | "여섯 시"로 **다시 만듦** |
| 자막 끊김 고치기 | 끊는 위치만 바뀜 | 그대로 |

- 화면에 보이는 표기(6시)와 소리 내어 읽는 말(여섯 시)을 따로 관리합니다. 그래서 자막 표기는 유지하면서 읽는 법만 바꿀 수 있습니다.

**주의**

- 음성을 다시 만든 뒤에는 **직접 들어서** 확인하세요. 자동 받아쓰기 결과가 맞다고 발음까지 맞는 것은 아닙니다.
- 이 수정은 **그 편에만** 적용됩니다. "앞으로 모든 영상에서 ○○는 항상 이렇게 읽기" 같은 공통 발음 사전은 아직 없습니다.

## 7. 출처·끝 크레딧

이 장이 출처·끝 크레딧 규칙의 기준입니다. 다른 장은 이 장을 가리킵니다.

**이럴 때** — 자료 출처를 더하거나, 표시가 실제 화면과 맞지 않을 때.

**이렇게 입력하세요**

```
<기사 URL> 편 끝 크레딧에 '<출처 문구>' 사진 출처를 추가해줘
```

```
<기사 URL> 편 출처 표기가 실제 화면에 나온 자료와 맞는지 확인해서 고쳐줘
```

**이렇게 됩니다**

- 끝 크레딧은 **좌측 정렬**, 사진·영상·음악 같은 **카테고리마다 줄을 바꿔** 표시됩니다. 한 장에 3초씩, 내용이 많으면 장이 늘어납니다.
- 화면 속 컷 출처는 기관 등 원자료가 지정한 출처만 해당 자료가 보이는 동안 표시됩니다. 스톡·생성 자료 출처는 끝 크레딧에 모읍니다.
- "음악" 줄은 공용 음원이면 **그 파일 이름**입니다(5장).

**주의**

- 끝 크레딧은 **빼거나 글자를 줄일 수 없습니다**(공통 규칙). 내용이 많으면 장이 늘어납니다.
- 출처 문구는 원자료가 정한 표기 그대로 씁니다. 임의로 줄여 달라는 요청은 반영하지 않습니다.
- 출처·끝 크레딧의 글꼴·배치 같은 디자인은 모든 영상 공통이라 이 요청으로 바뀌지 않습니다.

## 8. 확정·되돌리기·완성 영상 보기

**이럴 때 ① — 완성본을 확정할 때**

```
<기사 URL> 편 이대로 확정해줘
```

**이럴 때 ② — 예전 판으로 돌아갈 때**

```
<기사 URL> 편을 v1로 돌려줘
```

**이럴 때 ③ — 완성 영상을 보고 내려받을 때**

방법 A — 직접 열기 (Claude 없이):

1. Windows **파일 탐색기**를 엽니다.
2. 숏폼 제작 폴더 **shortform-news-liveaction**으로 갑니다.
3. **out** 폴더 → **videos.html**을 더블클릭합니다. 브라우저에 목록이 열립니다.

방법 B — Code 탭에 요청:

```
완성 영상 목록 열어줘
```

**이렇게 됩니다**

- 확정할 때마다 새 버전(v1, v2, …)이 생기고 **가장 마지막 버전이 확정본**입니다. 이전 판은 지워지지 않습니다.
- 되돌리기는 예전 판을 지우는 게 아니라 **그 영상을 새 버전으로 다시 확정**합니다(예: v3 = v1과 같은 영상).
- 목록은 확정할 때마다 자동으로 새로 만들어집니다. 이미 열어 둔 목록은 브라우저 **새로고침**을 누르세요.

| 목록에서 | 할 수 있는 것 |
|---|---|
| 편마다 "확정본 vN" | 재생·내려받기 |
| 다운로드 메뉴 «이전 판» | 예전 버전 내려받기 |
| 목록 아래 «제작 중» | 아직 확정 전인 편 |
| 영상 클릭 → 더보기 → 저장 폴더 열기 | 실제 파일 위치 |

**주의**

- 검수를 모두 통과해 끝난 편은 자동으로 확정됩니다. 직접 확정은 여러분이 보고 마무리할 때 씁니다.
- **백업**: 완성 영상과 공용 음원 파일은 **이 컴퓨터에만** 있습니다. 파일 탐색기 → shortform-news-liveaction 폴더에서 아래 두 폴더를 주기적으로 다른 곳에 복사해 두세요.

| 백업할 폴더 | 들어 있는 것 |
|---|---|
| `out` → `pilots` | 완성 영상(편마다 `deliver` 폴더) |
| `library` → `music` → `files` | 공용 음원 파일 |

## 9. 앞으로 모든 새 영상의 기본값 바꾸기

한 편이 아니라 **앞으로 새로 만드는 모든 영상**의 기본을 바꿀 때입니다.

**이렇게 입력하세요**

```
지금 기본값 보여줘
```

```
앞으로 모든 새 영상의 기본 보이스를 '<보이스 이름>'으로 바꿔줘
```

```
앞으로 모든 새 영상의 기본 제작 지시에 '<추가할 지시 문장>'을 추가해줘
```

**이렇게 됩니다**

- 기본값 보기: 제작 지시 버전, 자막 설정, 새 영상에 쓰일 보이스, 공용 음원 수 등이 표로 나옵니다.
- 보이스·제작 지시를 바꾸면 새 버전으로 기록되고 자동 저장됩니다. 바꾼 뒤 새 기본값 표를 다시 보여 줍니다.
- 제작 지시에 추가한 문장은 여러분이 적은 **원문 그대로** 들어갑니다.

**주의**

- **이미 만든 영상에는 적용되지 않습니다.** 새로 시작하는 영상부터 적용됩니다. 기존 영상을 바꾸려면 그 편을 지정해 따로 요청하세요(음성을 다시 만듭니다).
- 보이스는 Typecast 계정마다 다릅니다. 이름만 말하면 계정에서 해당 보이스를 확인합니다. 컴퓨터에 따로 등록된 보이스가 있어 적용되지 않는다는 안내가 나오면, 그 안내대로 어떻게 할지 답해 주세요.
- 바꿀 수 있는 기본값은 **보이스와 제작 지시 문장**입니다. 자막 크기·색, 후킹·출처 디자인, 로고 같은 **수치·모양**은 제작 지시 문장으로 바뀌지 않으니 "자막 크게"를 지시문에 넣지 마세요.
- 공용 음원 추가는 기본값이 아니라 5장입니다.

## 10. 자동으로 적용되는 것 — 다시 요청할 필요 없음

아래는 새 영상에 **기본으로 들어갑니다.** 매번 요청하지 않아도 됩니다. 고치는 법은 각 장에 있습니다.

| 항목 | 기본 동작 | 확인하는 법 | 고칠 때 |
|---|---|---|---|
| 안전영역 | 자막·출처가 유튜브 모바일 화면의 버튼·설명 글에 가리지 않는 위치 | 휴대폰에서 실제 재생해 가림 여부 확인 | 가림이 보이면 알려 주세요 |
| 끝 크레딧 | 좌측 정렬, 카테고리별 줄바꿈, 장당 3초 | 영상 마지막 부분 | 7장 |
| 숫자 읽기 | 화면 표기와 읽는 말을 따로 적어 자연스럽게 낭독 | 숫자가 나오는 곳을 직접 듣기 | 6장 |
| 쉼표 자막 | 쉼표 뒤는 다음 자막으로, 자막은 한 줄, 이름은 한 자막에 묶음 | 쉼표·기관명이 있는 문장 | 6장 |
| 후킹 강조 | 첫 문장 핵심을 큰 중앙 문구 + 노란 밑줄로 초반에 한 번 | 영상 첫 몇 초 | 3장 |

**확인을 요청하려면**

```
<기사 URL> 편 자막·출처·끝 크레딧·후킹이 기본 기준대로 들어갔는지 정지 화면으로 보여줘
```

→ 해당 장면의 정지 화면을 대화 화면에 보여 줍니다(영상 전체를 다시 만들지 않습니다).

**주의**

- 숫자 읽기는 원고를 쓸 때마다 적용하는 방식입니다. 드물게 틀릴 수 있으니 숫자가 있는 곳은 들어 보세요.
- 자막 가로 폭은 모바일 실측 전 잠정값입니다.
