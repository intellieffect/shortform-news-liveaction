시작 전에

요청 화면 열기 — 매번 이 순서로

  1. Claude 앱 → 위쪽 탭 Code (Chat·Cowork 탭에서는 동작하지 않습니다)
  2. 입력창 아래 실행 위치 → Local
  3. 입력창 아래 폴더 선택 → shortform-news-liveaction (목록에 없으면 폴더 선택 → 다른 폴더 열기 → 그 폴더)
  4. 폴더 옆 worktree(작업 복사본)는 켜지 않습니다
  5. 요청을 적고 Enter. 확인 창이 뜨면 허용

꼭 지킬 네 가지

  1. 한 번에 한 편씩 요청합니다.
  2. 같은 기사 = 같은 편입니다. 만든 기사 주소를 다시 넣으면 그 편을 이어서 고칩니다.
  3. 고칠 때는 문장 앞에 기사 주소(URL)를 붙입니다.
  4. 이번에 적은 조건이 기본값보다 우선합니다.

파일 이름이 끝 크레딧 음악 줄이 됩니다. 예: 새벽 공기 by 홍길동.mp3 → 음악 줄 "새벽 공기 by 홍길동". 원하는 표기로 이름을 바꾼 뒤 넣으세요.

이 음원 공용 음원 폴더에 넣어줘
공용 음원 목록 보여줘
<기사 URL> 편 배경음악으로 공용 음원 폴더의 '<파일 이름>' 써줘
<기사 URL> 편 배경음악을 조금 더 작게 해줘
이렇게 됩니다되묻지 않고 바로 넣고, 그 편에 쓰면 끝 크레딧 음악 줄이 파일 이름으로 채워집니다. 새 영상을 만들 때도 공용 폴더의 곡을 먼저 후보로 씁니다.
참고음원의 라이선스·사용 범위 확인은 한겨레가 맡습니다. 공용 폴더에 넣은 음원은 써도 되는 것으로 보고 씁니다.

앞으로 계속 쓰게 반영하기 — 기본값

이럴 때한 편에서 고쳐 본 것을 앞으로 만드는 모든 새 영상에 쓰고 싶을 때.
순서① 이번 편에서 먼저 시험 → ② 마음에 들면 반영 → ③ 새 영상부터 적용
이렇게 입력하세요① 아래 표처럼 그 편에서 고쳐 보고 ② 마음에 들면:
<기사 URL> 편에서 고친 것 앞으로 계속 쓰게 반영해줘
이렇게 됩니다
설정① 그 편에서 고쳐 보기 (예)② 반영하면
보이스<URL> 편 보이스를 '<이름>'으로 바꿔줘 (음성 다시 만듦)새 기본 보이스
자막<URL> 편 말자막을 조금 크게 해줘새 기본 자막
후킹 디자인<URL> 편 후킹 밑줄 색을 '<색>'으로 고쳐줘새 기본 후킹 디자인
크레딧 디자인<URL> 편 끝 크레딧 글자를 조금 크게 해줘새 기본 크레딧 디자인
기본 제작 지시1장 요청 뒤에 조건으로 붙여 시험 → 앞으로 모든 새 영상의 기본 제작 지시에 '<문장>'을 추가해줘적은 그대로 추가

반영하면 바뀐 항목(이전 → 새 값)을 보여 주고 자동 저장됩니다. 반영되는 것은 표의 설정뿐이고, 그 편의 문구·원고·컷은 기본값이 되지 않습니다. 지금 값은 지금 기본값 보여줘, 편 없이 바로 바꾸려면 앞으로 모든 새 영상의 기본 보이스를 '<이름>'으로 바꿔줘.

주의이미 만든 영상에는 적용되지 않습니다. 반영한 뒤 새로 시작하는 영상부터 적용되고, 기존 영상은 다시 만들어도 그대로입니다. 기본값을 이전으로 되돌리는 문장은 이 매뉴얼에 없으니, 필요하면 인텔리이펙트에 문의하세요.
