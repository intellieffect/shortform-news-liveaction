# 한겨레 숏폼 제작 — 활용 매뉴얼

| 문서 버전 | 발행일 | 기준 |
|---|---|---|
| v1.1 | 2026-09-30 | 숏폼 뉴스 제작 플러그인 1.6.0 기준 |

## 처음이라면 — 이 세 가지만

1. 0장 순서대로 요청 화면을 엽니다: **Claude 앱 → Code 탭 → Local → shortform-news-liveaction 폴더**
2. `<기사 URL> 이 기사로 숏폼 만들어줘` 입력 → **Enter**
3. 끝나면 `완성 영상 목록 열어줘` → 재생·내려받기

회색 상자의 문장을 복사해 `< >` 부분만 바꿔 입력하세요. 화살표(→)는 누르는 순서입니다.

## 용어

| 용어 | 뜻 |
|---|---|
| 편 | 기사 한 건으로 만든 영상. 같은 기사 = 같은 편 |
| 확정본 | 완성 영상 목록의 마지막 버전(v1, v2 …) |
| 후킹 | 영상 첫머리에 크게 뜨는 문구와 노란 밑줄 |

| 기본값 | 새 영상에 쓰는 보이스·자막·후킹 디자인·크레딧 디자인·기본 제작 지시 |

## 0. 시작 전에

**요청 화면 열기 — 매번 이 순서로**

1. **Claude 앱** → **Code 탭**(화면 위쪽. Chat·Cowork 탭에서는 동작하지 않습니다)
2. 입력창 주변의 실행 위치(환경) 선택 → **Local**
3. 입력창 주변의 폴더 선택 → **shortform-news-liveaction** (목록에 없으면 폴더 선택에서 다른 폴더를 찾아 이 폴더를 고릅니다)
4. **worktree(작업 복사본)** 선택이 보이면 **켜지 않습니다**
5. 요청을 적고 **Enter**. 확인 창이 뜨면 **허용**(Allow)

> 앱 버전에 따라 메뉴 이름·위치가 조금 다를 수 있습니다. 같은 뜻의 항목을 고르세요.

**꼭 지킬 네 가지**

1. **한 번에 한 편**씩 요청합니다.
2. **같은 기사 = 같은 편**입니다. 만든 기사 주소를 다시 넣으면 그 편을 이어서 고칩니다.
3. 고칠 때는 문장 앞에 **기사 주소(URL)**를 붙입니다.
4. **이번에 적은 조건이 기본값보다 우선**합니다.

**결과를 보는 곳**

| 보고 싶은 것 | 보는 곳 |
|---|---|
| 진행 안내·구성안·썸네일 후보·질문 | Code 탭 대화 화면 |
| 완성 영상 재생·내려받기·이전 판 | 완성 영상 목록 (8장) |

**고친 뒤에는**

3~7장처럼 고치기가 끝나면 **새 버전(v2, v3 …)으로 확정됩니다.** 이전 판은 지워지지 않습니다. 완성 영상 목록에 새 버전이 보이지 않으면 `<기사 URL> 편 이대로 확정해줘`(8장)로 지금 상태를 확정하세요.

## 1. 새 영상 만들기

기사 하나로 새 숏폼을 만들 때.

```
<기사 URL> 이 기사로 숏폼 만들어줘
```

```
<기사 URL> 이 기사로 숏폼 만들어줘. 끝 크레딧 시간은 빼고 본문만 60초 안팎으로 해줘
```

- 기본 제작 지시(60~90초)로 완성본까지 중간에 묻지 않고 만들고, 썸네일 후보도 함께 대화 화면에 보여 줍니다.
- 검수를 통과하면 자동으로 확정되어 완성 영상 목록에 올라갑니다.

> "전체 ○초"라고 적으면 끝 크레딧까지 포함한 길이입니다. 창을 닫았거나 끊겼으면 새 대화에서 같은 기사 주소로 다시 요청하세요. 만들던 편을 이어서 합니다.

## 2. 음성 전에 멈추고 구성안 보기

음성을 만들기 전에 구성안·원고·후킹 문구를 먼저 보고 싶을 때.

```
<기사 URL> 이 기사로 숏폼 만들어줘. 음성 만들기 전에 구성안·원고·후킹 문구를 보여주고 멈춰줘
```

멈춘 뒤 답하기:

```
진행해줘
```

```
후킹 문구를 '<새 문구>'로 바꾸고 진행해줘
```

- 평소 제작을 음성 직전에 멈추고 구성안·원고 전문·후킹 문구·배경음악 후보·예상 분량을 보여 줍니다.
- 답하면 반영해 음성부터 끝까지 진행합니다.

**주의** — 멈춘 상태에서는 다른 기사를 요청하지 말고 먼저 이 편에 답하세요.

## 3. 후킹 문구 바꾸기

영상 첫머리에 크게 뜨는 문구를 바꿀 때. (밑줄 색 같은 후킹 디자인은 9장)

```
<기사 URL> 편 후킹 화면 문구를 '<새 문구>'로 바꿔줘. 음성은 그대로 둬
```

```
<기사 URL> 편 첫 문장을 '<새 문장>'으로 바꾸고 후킹 문구도 맞춰줘
```

| 요청 | 바뀌는 것 | 음성 |
|---|---|---|
| 화면 문구만 | 첫머리 문구 | 그대로 |
| 첫 문장까지 | 첫 문장 + 화면 문구 | **다시 만듦** |

> 화면 문구는 첫 문장과 같은 핵심이어야 합니다. 뜻이 어긋나면 첫 문장도 고치게 되어 음성을 다시 만듭니다.

## 4. 장면·컷·카메라 — 이 편에만

한 장면이 너무 길거나, 컷·움직임·도식을 더하고 싶을 때.

```
<기사 URL> 편 보름달 장면이 너무 길어. 관련 사진 컷을 하나 더 넣어 두 컷으로 나눠줘
```

```
<기사 URL> 편 행성 장면에 천천히 다가가는 카메라 움직임(줌인)을 넣어줘
```

```
<기사 URL> 편에서 두 수치를 막대 비교 도식으로 보여줘
```

- 그 장면만 고치고 다시 검수합니다. 원고를 바꾸지 않으면 음성은 그대로입니다.
- 장면은 "0:40쯤 보름달 장면"처럼 대상이나 시간으로 가리키세요.

> 장면 4초 이하·2컷·카메라 움직임·수치 카운트업·효과음·인포그래픽·상단 제목 바를 **모든 영상에 자동**으로 넣는 기능은 아직 없습니다. 편마다 요청하세요.

## 5. 배경음악 — 공용 음원 폴더

한겨레 음원을 여러 영상에서 다시 쓰고 싶을 때.

**공용 음원 폴더** = shortform-news-liveaction → library → music → files. 폴더에 직접 복사하지 말고 아래처럼 대화창으로 넣으세요.

**파일 이름이 끝 크레딧 음악 줄이 됩니다.** 예: `새벽 공기 by 홍길동.mp3` → 음악 줄 "새벽 공기 by 홍길동". 원하는 표기로 이름을 바꾼 뒤 넣으세요.

음원 파일을 입력창에 끌어다 놓고(또는 입력창의 **+** 버튼으로 첨부, 인터넷 주소면 붙여 넣기):

```
이 음원 공용 음원 폴더에 넣어줘
```

```
공용 음원 목록 보여줘
```

```
<기사 URL> 편 배경음악으로 공용 음원 폴더의 '<파일 이름>' 써줘
```

```
<기사 URL> 편 배경음악을 조금 더 작게 해줘
```

- 넣어 달라고 하면 바로 넣습니다. 그 편에 쓰면 끝 크레딧 음악 줄이 파일 이름으로 채워집니다.
- 새 영상을 만들 때도 공용 폴더의 곡을 먼저 후보로 씁니다.

> 음원의 라이선스·사용 범위 확인은 한겨레가 맡습니다. 공용 폴더에 넣은 음원은 써도 되는 것으로 보고 씁니다.

## 6. 발음·자막 끊김 고치기

숫자를 잘못 읽거나, 자막이 어색한 곳에서 끊길 때.

```
<기사 URL> 편에서 '6시'를 '여섯 시'로 읽게 고쳐줘
```

```
<기사 URL> 편 자막에서 '국제 달 관측의 날'이 둘로 끊겼어. 음성은 그대로 두고 자막만 다시 나눠줘
```

| 요청 | 화면 자막 | 음성 |
|---|---|---|
| 읽는 법 | "6시" 그대로 | "여섯 시"로 **다시 만듦** |
| 자막 끊김 | 끊는 위치만 바뀜 | 그대로 |

> 다시 만든 음성은 직접 들어 확인하세요. 이 수정은 그 편에만 적용됩니다.

## 7. 출처·끝 크레딧

자료 출처를 더할 때.

```
<기사 URL> 편 끝 크레딧에 '<출처 문구>' 사진 출처를 추가해줘
```

- 끝 크레딧은 좌측 정렬, 사진·영상·음악 카테고리별로 줄을 바꾸고 한 장에 3초씩 보입니다.

> 끝 크레딧은 빼거나 줄일 수 없습니다. 내용이 많으면 장이 늘어납니다.

## 8. 확정·되돌리기·완성 영상 보기

```
<기사 URL> 편 이대로 확정해줘
```

```
<기사 URL> 편을 v1로 돌려줘
```

```
완성 영상 목록 열어줘
```

Claude 없이 보려면: 파일 탐색기 → **shortform-news-liveaction** → **out** → **videos.html** 더블클릭

- 확정할 때마다 새 버전(v1, v2 …)이 쌓이고 **마지막 버전이 확정본**입니다.
- 버전과 이전 판은 목록에서 보고 내려받습니다. 열어 둔 목록은 브라우저 새로고침(F5)을 누르세요.
- 되돌리기 예: v3까지 있는 편에 `v1로 돌려줘` → v1과 같은 영상이 **v4**로 확정되고 v1~v3은 그대로 남습니다.

**주의** — 완성 영상(`out` → `pilots`)과 공용 음원(`library` → `music` → `files`)은 **이 컴퓨터에만** 있습니다. 주기적으로 다른 곳에 복사해 두세요.

## 9. 앞으로 계속 쓰게 반영하기 — 기본값

한 편에서 고쳐 본 것을 앞으로 만드는 모든 새 영상에 쓰고 싶을 때.

① 이번 편에서 먼저 시험 → ② 마음에 들면 반영 → ③ 새 영상부터 적용

① 아래 표처럼 그 편에서 고쳐 보고 ② 마음에 들면:

```
<기사 URL> 편에서 고친 것 앞으로 계속 쓰게 반영해줘
```

| 설정 | ① 그 편에서 고쳐 보기 (예) | ② 반영하면 |
|---|---|---|
| 보이스 | `<URL> 편 보이스를 '<이름>'으로 바꿔줘` (음성 다시 만듦) | 새 기본 보이스 |
| 자막 | `<URL> 편 말자막을 조금 크게 해줘` | 새 기본 자막 |
| 후킹 디자인 | `<URL> 편 후킹 밑줄 색을 '<색>'으로 고쳐줘` | 새 기본 후킹 디자인 |
| 크레딧 디자인 | `<URL> 편 끝 크레딧 글자를 조금 크게 해줘` | 새 기본 크레딧 디자인 |
| 기본 제작 지시 | 1장 요청 뒤에 조건으로 붙여 시험 → `앞으로 모든 새 영상의 기본 제작 지시에 '<문장>'을 추가해줘` | 적은 그대로 추가 |

- 반영하면 바뀐 항목(이전 → 새 값)을 보여 주고 자동 저장됩니다.
- 반영되는 것은 표의 설정뿐이고, 그 편의 문구·원고·컷은 기본값이 되지 않습니다.
- 지금 값은 `지금 기본값 보여줘`, 편 없이 바로 바꾸려면 `앞으로 모든 새 영상의 기본 보이스를 '<이름>'으로 바꿔줘`.

**주의** — **이미 만든 영상에는 적용되지 않습니다.** 반영한 뒤 새로 시작하는 영상부터 적용되고, 기존 영상은 다시 만들어도 그대로입니다. 기본값을 이전으로 되돌리는 문장은 이 매뉴얼에 없으니, 필요하면 인텔리이펙트에 문의하세요.

## 10. 자동으로 적용되는 것

아래는 요청하지 않아도 새 영상에 들어갑니다.

| 항목 | 기본 동작 | 고칠 때 |
|---|---|---|
| 안전영역 | 자막·출처가 유튜브 모바일 화면의 버튼·설명 글에 가리지 않는 위치 | 가림이 보이면 알려 주세요 |
| 끝 크레딧 | 좌측 정렬, 카테고리별 줄바꿈, 장당 3초 | 7장 |
| 숫자 읽기 | 화면 표기와 읽는 말을 따로 적어 자연스럽게 낭독 | 6장 |
| 자막 | 한 줄, 쉼표 뒤는 다음 자막, 이름은 한 자막에 묶음 | 6장 |
| 후킹 | 첫 문장 핵심을 큰 중앙 문구 + 노란 밑줄로 초반에 한 번 | 3장 |

기본대로 들어갔는지 확인하려면:

```
<기사 URL> 편 자막·출처·끝 크레딧·후킹이 기본 기준대로 들어갔는지 정지 화면으로 보여줘
```

> 자막·후킹·크레딧의 크기·색·위치를 바꾸려면 9장처럼 편에서 고쳐 보고 반영하세요. 기본 제작 지시에 문장을 추가해서는 바뀌지 않습니다.

## 부록 A. 자주 막히는 상황

| 상황 | 이렇게 하세요 |
|---|---|
| 제작 도구가 없다는 답이 온다 | 0장 1~4를 다시 확인(Code 탭 · Local · 제작 폴더) |
| 확정했는데 목록에 안 보인다 | worktree 없이 새 대화를 열고 `<기사 URL> 편 이어서 확정해줘` |
| "API 키가 없다"·음성이 안 만들어진다 | 파일 탐색기 → shortform-news-liveaction → **API 키 등록.cmd** 더블클릭. 키를 대화창에 붙여 넣지 마세요 |
| 무엇이 문제인지 모르겠다 | 아래 문장 입력, 또는 같은 폴더의 **환경 점검.cmd** 더블클릭 |

