시작 전에

꼭 지킬 네 가지

  1. 반드시 Code 탭에서 요청합니다. 일반 채팅 탭에서는 제작 도구가 동작하지 않습니다. Code 탭을 열 때 한겨레 숏폼 제작 폴더가 선택되어 있는지 확인하세요.
  2. 한 번에 한 편씩 요청합니다. 한 편이 끝나거나 멈춘 뒤 다음 기사를 요청하세요.
  3. 같은 기사 = 같은 영상입니다. 이미 만든 기사 주소를 다시 넣으면 새로 만들지 않고 그 영상을 이어서 고칩니다.
  4. 이번에 적은 요청이 기본 설정보다 우선합니다. "45초로", "음성 전에 멈춰줘"처럼 적은 조건은 기본 제작 방식보다 먼저 적용됩니다.

결과를 보는 곳

보고 싶은 것보는 곳
제작 중 안내·구성안·질문Code 탭 대화 화면
완성 영상·이전 판 내려받기"완성 영상 목록"(8장)

요청할 때 편을 가리키는 법: 고칠 때는 문장 앞에 기사 주소(URL)를 붙이세요. 주소 없이 "아까 거 고쳐줘"라고 하면 Claude가 어느 영상인지 한 번 되묻습니다.

1

새 영상 만들기

이럴 때기사 하나로 새 숏폼을 만들 때.
이렇게 입력하세요
<기사 URL> 이 기사로 숏폼 만들어줘
<기사 URL> 이 기사로 숏폼 만들어줘. 끝 크레딧 시간은 빼고 본문만 60초 안팎으로 해줘
이렇게 됩니다
  • 기본 제작 지시(60~90초, 일반 시청자 대상)가 자동으로 적용됩니다. 긴 지시문을 붙여 넣을 필요가 없습니다.
  • 기사 확인 → 자료 수집 → 원고 → 음성 → 화면 → 검수 → 완성본까지 중간에 묻지 않고 진행합니다. 썸네일 후보도 함께 만듭니다.
  • 끝나면 대화 화면에 완성 영상과 중요한 선택·남은 한계가 정리됩니다.
주의
  • 분량을 "본문만 ○초"라고 적으면 끝 크레딧 시간은 따로 더해집니다. "전체 ○초"라고 적으면 크레딧까지 포함한 길이입니다.
  • 이미 만든 기사 주소를 넣으면 "이미 있는 영상"이라고 알려 줍니다. 그대로 이어서 고치는 요청을 하면 됩니다.
  • 한 편 제작에는 시간이 걸리고, 음성·이미지·영상 생성 크레딧이 사용됩니다.
2

음성 만들기 전에 구성안 확인하고 멈추기

이럴 때음성을 만들기 전에 구성과 원고, 후킹 문구를 먼저 보고 싶을 때.
이렇게 입력하세요
<기사 URL> 이 기사로 숏폼 만들어줘. 음성 만들기 전에 구성안·원고·후킹 문구를 보여주고 멈춰줘

멈춘 뒤 답하는 법:

진행해줘
후킹 문구를 '<새 문구>'로 바꾸고 진행해줘
원고 세 번째 문장을 '<새 문장>'으로 고치고 다시 보여줘
이렇게 됩니다
  • 기사 확인·자료 수집·원고 작성까지 한 뒤, 음성을 만들기 직전에 멈추고 대화 화면에 아래를 보여 줍니다.
보여 주는 것내용
구성안구간 순서, 구간마다 맡는 일과 주요 화면 한 줄씩
원고낭독 원고 전문 (첫 문장 = 후킹 문장 표시)
후킹 문구화면에 크게 뜰 문구, 줄 구성, 밑줄 위치
배경음악 후보·예상 분량
  • "진행해줘"라고 하면 그대로 음성부터 끝까지 진행합니다.
  • 고칠 내용을 말하면 반영하고 진행합니다. "다시 보여줘"를 붙이면 고친 결과를 보여 주고 다시 멈춥니다.
주의
  • 멈춤 조건을 적지 않으면 멈추지 않고 끝까지 만듭니다(기본 동작).
  • 이 기능은 기사로 구성안을 따로 자동 생성하는 기능이 아니라, 평소 제작 흐름을 음성 직전에 잠시 세우는 방식입니다.
  • 멈춘 상태에서 다른 기사를 요청하지 마세요. 먼저 "진행해줘" 또는 수정 답변으로 이 편을 이어 가세요.
3

후킹 문구 바꾸기

이럴 때영상 첫머리에 크게 뜨는 문구(노란 밑줄)를 바꾸고 싶을 때.

두 가지 경우가 있습니다.

화면 문구만첫 문장까지
바뀌는 것화면에 크게 뜨는 문구내레이션 첫 문장 + 화면 문구
음성그대로다시 만듦 (크레딧 사용)
언제첫 문장은 좋은데 화면 문구만 짧게·세게첫 문장 자체를 바꾸고 싶을 때
이렇게 입력하세요
<기사 URL> 편 후킹 화면 문구를 '<새 문구>'로 바꿔줘. 음성은 그대로 둬
<기사 URL> 편 첫 문장을 '<새 문장>'으로 바꾸고 후킹 문구도 맞춰줘
이렇게 됩니다
  • 화면 문구만 바꾸면 음성과 일반 자막은 그대로이고 첫머리 문구만 바뀝니다.
  • 첫 문장까지 바꾸면 음성을 새로 만들고 자막·화면 타이밍도 다시 맞춥니다.
  • 고친 뒤 확정하면 새 버전으로 쌓입니다(8장).
주의
  • 화면 문구는 첫 문장과 같은 핵심이어야 합니다. 새 문구가 첫 문장과 뜻이 어긋나면 첫 문장도 맞춰 고쳐야 하고, 그러면 음성을 다시 만듭니다.
  • 후킹은 영상 초반에 한 번만 등장합니다. 중간에 다시 띄우는 요청은 기본 규칙과 맞지 않습니다.
  • 글꼴·밑줄 색 같은 디자인 자체를 바꾸는 것은 11장(인텔리이펙트 요청)입니다.
4

장면·컷·카메라·도식을 이 편에만 요청하기

이럴 때특정 장면이 길게 머물거나, 움직임·도식을 더하고 싶을 때. 그 영상 한 편에만 적용됩니다.
이렇게 입력하세요
<기사 URL> 편 보름달 장면이 너무 길어. 관련 사진 컷을 하나 더 넣어 두 컷으로 나눠줘
<기사 URL> 편 행성 장면에 천천히 다가가는 카메라 움직임(줌인)을 넣어줘
<기사 URL> 편에서 두 수치를 막대 비교 도식으로 보여줘
이렇게 됩니다
  • 해당 장면만 고치고 나머지는 유지합니다. 음성은 원고를 바꾸지 않는 한 그대로입니다.
  • 고친 뒤 다시 검수하고, 결과를 대화 화면에 보여 줍니다.
주의
  • 장면이 어디인지 기사 속 대상이나 대략의 시간(예: "0:40쯤 보름달 장면")으로 알려 주면 정확합니다.
  • 추가 컷은 기사와 관련된 실제 자료나 상상도로 넣습니다. 알맞은 자료가 없으면 그 사실을 알려 줍니다.
  • "앞으로 모든 영상을 장면 4초 이하로", "모든 문장 2컷", "카메라 움직임 기본 적용"처럼 모든 영상에 자동 적용하는 것은 지금 제공되지 않습니다(11장).
5

배경음악 — 공용 음원 폴더

한겨레가 보유한 음원을 공용 음원 폴더에 넣어 두면 여러 영상에서 다시 쓸 수 있습니다. 폴더에 파일을 직접 넣지 말고 Claude에게 요청하세요. 그래야 라이선스·출처·끝 크레딧 문구가 함께 기록됩니다.

이럴 때 ① — 음원을 공용 폴더에 넣을 때

음원 파일을 Code 탭 대화창에 끌어다 놓거나, 음원 주소를 붙인 뒤:

이 음원 공용 음원 폴더에 넣어줘. 라이선스: <라이선스 원문>, 끝 크레딧: <크레딧 문구>, 사용 범위: <예: 한겨레 숏폼>

이럴 때 ② — 들어 있는 음원을 볼 때

공용 음원 목록 보여줘

이럴 때 ③ — 이 편에 쓰거나 음량을 조절할 때

<기사 URL> 편 배경음악을 공용 폴더의 '<곡 이름>'으로 바꿔줘
<기사 URL> 편 배경음악을 조금 더 작게 해줘
이렇게 됩니다
  • 넣기: 목록에 곡·라이선스·출처·크레딧이 기록되고 자동 저장됩니다. 같은 파일을 두 번 넣으면 이미 있다고 알려 줍니다.
  • 목록: 곡 이름·라이선스·사용 범위·크레딧·파일 있음 여부가 표로 나옵니다.
  • 이 편에 쓰기: 음원이 그 영상에 연결되고, 권리 기록과 끝 크레딧 "음악" 줄이 자동으로 채워집니다.
  • 새 영상을 만들 때도 Claude가 공용 폴더를 먼저 살펴보고 맞는 곡이 있으면 후보로 씁니다.
주의
  • 라이선스는 반드시 적어 주세요. 없으면 넣지 않고 되묻습니다. 적어 준 문장은 고치지 않고 그대로 기록합니다.
  • 끝 크레딧 문구를 안 적으면 필요한지 되묻습니다.
  • 음원 파일은 이 컴퓨터에만 저장됩니다. 완성 영상과 함께 주기적으로 백업하세요(8장).
  • 곡 이름이 여러 곡에 맞으면 어느 곡인지 되묻습니다.
6

발음·숫자·자막 끊김 고치기

이럴 때숫자를 잘못 읽거나, 자막이 어색한 곳에서 끊길 때.
이렇게 입력하세요
<기사 URL> 편에서 '6시'를 '여섯 시'로 읽게 고쳐줘
<기사 URL> 편 자막에서 '국제 달 관측의 날'이 둘로 끊겼어. 음성은 그대로 두고 자막만 다시 나눠줘
이렇게 됩니다
요청화면 자막음성
읽는 법 고치기"6시" 그대로"여섯 시"로 다시 만듦
자막 끊김 고치기끊는 위치만 바뀜그대로
  • 화면에 보이는 표기(6시)와 소리 내어 읽는 말(여섯 시)을 따로 관리합니다. 그래서 자막 표기는 유지하면서 읽는 법만 바꿀 수 있습니다.
주의
  • 음성을 다시 만든 뒤에는 직접 들어서 확인하세요. 자동 받아쓰기 결과가 맞다고 발음까지 맞는 것은 아닙니다.
  • 이 수정은 그 편에만 적용됩니다. "앞으로 모든 영상에서 ○○는 항상 이렇게 읽기" 같은 공통 발음 사전은 아직 없습니다.
7

출처·끝 크레딧

이럴 때자료 출처를 더하거나, 표시가 실제 화면과 맞지 않을 때.
이렇게 입력하세요
<기사 URL> 편 끝 크레딧에 '<출처 문구>' 사진 출처를 추가해줘
<기사 URL> 편 출처 표기가 실제 화면에 나온 자료와 맞는지 확인해서 고쳐줘
이렇게 됩니다
  • 끝 크레딧은 좌측 정렬, 사진·영상·음악 같은 카테고리마다 줄을 바꿔 표시됩니다. 한 장에 3초씩, 내용이 많으면 장이 늘어납니다.
  • 화면 속 컷 출처는 기관 등 원자료가 지정한 출처만 해당 자료가 보이는 동안 표시됩니다. 스톡·생성 자료 출처는 끝 크레딧에 모읍니다.
주의
  • 끝 크레딧은 빼거나 글자를 줄일 수 없습니다(공통 규칙). 내용이 많으면 장이 늘어납니다.
  • 출처 문구는 원자료가 정한 표기 그대로 씁니다. 임의로 줄여 달라는 요청은 반영하지 않습니다.
8

확정·이전 버전으로 되돌리기

이럴 때완성본을 확정하거나, 예전 판으로 돌아가고 싶을 때.
이렇게 입력하세요
<기사 URL> 편 이대로 확정해줘
<기사 URL> 편을 v1로 돌려줘
완성 영상 목록 열어줘
이렇게 됩니다
  • 확정할 때마다 새 버전(v1, v2, …)이 생기고 가장 마지막 버전이 확정본입니다. 이전 판은 지워지지 않습니다.
  • 되돌리기는 예전 판을 지우는 게 아니라 그 영상을 새 버전으로 다시 확정합니다(예: v3 = v1과 같은 영상).
  • 완성 영상 목록이 브라우저로 열립니다.
목록에서할 수 있는 것
편마다 "확정본 vN"재생·내려받기
다운로드 메뉴 «이전 판»예전 버전 내려받기
목록 아래 «제작 중»아직 확정 전인 편
영상 클릭 → 더보기 → 저장 폴더 열기실제 파일 위치
주의
  • 검수를 모두 통과해 끝난 편은 자동으로 확정됩니다. 직접 확정은 여러분이 보고 마무리할 때 씁니다.
  • 영상 파일은 이 컴퓨터에만 있습니다. 목록의 "저장 폴더 열기"로 폴더를 열어 주기적으로 다른 곳에 복사해 두세요.
