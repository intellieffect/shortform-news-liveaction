시작 전에

요청 화면 열기 — 매번 이 순서로

  1. Claude 앱 → 위쪽 탭 Code (Chat·Cowork 탭에서는 동작하지 않습니다)
  2. 입력창 아래 실행 위치 → Local
  3. 입력창 아래 폴더 선택 → shortform-news-liveaction (목록에 없으면 폴더 선택 → 다른 폴더 열기 → 그 폴더)
  4. 폴더 옆 worktree(작업 복사본)는 켜지 않습니다
  5. 요청을 적고 Enter. 확인 창이 뜨면 허용

꼭 지킬 네 가지

  1. 한 번에 한 편씩 요청합니다.
  2. 같은 기사 = 같은 영상입니다. 만든 기사 주소를 다시 넣으면 그 영상을 이어서 고칩니다.
  3. 고칠 때는 문장 앞에 기사 주소(URL)를 붙입니다.
  4. 이번에 적은 조건이 기본 설정보다 우선합니다.

새 영상 만들기

이럴 때기사 하나로 새 숏폼을 만들 때.
이렇게 입력하세요
<기사 URL> 이 기사로 숏폼 만들어줘
<기사 URL> 이 기사로 숏폼 만들어줘. 끝 크레딧 시간은 빼고 본문만 60초 안팎으로 해줘
이렇게 됩니다
  • 기본 제작 지시(60~90초)로 완성본까지 중간에 묻지 않고 만들고, 썸네일 후보도 함께 만듭니다.
  • 검수를 통과하면 자동으로 확정되어 완성 영상 목록에 올라갑니다.
주의"전체 ○초"라고 적으면 끝 크레딧까지 포함한 길이입니다.

이렇게 입력하세요
<기사 URL> 이 기사로 숏폼 만들어줘. 음성 만들기 전에 구성안·원고·후킹 문구를 보여주고 멈춰줘

멈춘 뒤 답하기:

진행해줘
후킹 문구를 '<새 문구>'로 바꾸고 진행해줘
이렇게 됩니다

  • 답하면 반영해 음성부터 끝까지 진행합니다.
주의멈춘 상태에서는 다른 기사를 요청하지 말고 먼저 이 편에 답하세요.

<기사 URL> 편 후킹 화면 문구를 '<새 문구>'로 바꿔줘. 음성은 그대로 둬
<기사 URL> 편 첫 문장을 '<새 문장>'으로 바꾸고 후킹 문구도 맞춰줘

<기사 URL> 편 행성 장면에 천천히 다가가는 카메라 움직임(줌인)을 넣어줘

배경음악 — 공용 음원 폴더

이럴 때한겨레 음원을 여러 영상에서 다시 쓰고 싶을 때.

파일 이름이 끝 크레딧에 그대로 들어갑니다. 파일 이름(확장자 제외)이 끝 크레딧 "음악" 줄이 되니, 원하는 표기로 이름을 바꾼 뒤 넣으세요. 예: Music - 새벽 공기 by 홍길동.mp3 → Music - 새벽 공기 by 홍길동

이렇게 입력하세요

음원 파일을 입력창에 끌어다 놓고(또는 + → 파일 첨부, 인터넷 주소면 붙여 넣기):

이 음원 공용 음원 폴더에 넣어줘
공용 음원 목록 보여줘
<기사 URL> 편 배경음악으로 공용 음원 폴더의 '<파일 이름>' 써줘
<기사 URL> 편 배경음악을 조금 더 작게 해줘
이렇게 됩니다되묻지 않고 바로 넣고, 그 편에 쓰면 끝 크레딧 "음악" 줄이 파일 이름으로 채워집니다. 새 영상을 만들 때도 공용 폴더의 곡을 먼저 후보로 씁니다.
주의음원의 라이선스·사용 범위 확인은 한겨레가 맡습니다. 공용 폴더에 넣은 음원은 써도 되는 것으로 보고 씁니다.
