시작 전에

요청 화면 열기 — 매번 이 순서로

  1. Claude 앱 → Code 탭(화면 위쪽. Chat·Cowork 탭에서는 동작하지 않습니다)
  2. 입력창 주변의 실행 위치(환경) 선택 → Local
  3. 입력창 주변의 폴더 선택 → shortform-news-liveaction (목록에 없으면 폴더 선택에서 다른 폴더를 찾아 이 폴더를 고릅니다)
  4. worktree(작업 복사본) 선택이 보이면 켜지 않습니다
  5. 입력창 주변의 모델 선택 → Opus 5.5 (지금의 영상 품질은 이 모델 기준으로 맞춰져 있습니다. 다른 모델을 쓰면 품질이 일정하지 않을 수 있습니다)
  6. 요청을 적고 Enter. 확인 창이 뜨면 허용(Allow)

앱 버전에 따라 메뉴 이름·위치가 조금 다를 수 있습니다. 같은 뜻의 항목을 고르세요.

꼭 지킬 네 가지

  1. 한 번에 한 편씩 요청합니다.
  2. 같은 기사 = 같은 편입니다. 만든 기사 주소를 다시 넣으면 그 편을 이어서 고칩니다.
  3. 고칠 때는 문장 앞에 기사 주소(URL)를 붙입니다.
  4. 이번에 적은 조건이 기본값보다 우선합니다.

① 타입캐스트에서 만든 목소리의 ID를 복사합니다. 커스텀 목소리 ID는 uc_로 시작합니다.

② 복사한 ID로 먼저 시험합니다.

타입캐스트 커스텀 보이스 <복사한 ID>를 기본 목소리로 바꿔줘. 바꾸기 전에 이 목소리로 짧은 테스트 문장을 만들어서 들려줘.

③ 마음에 들면 고정합니다.

좋아, 이 목소리를 앞으로 기본값으로 고정해줘.
