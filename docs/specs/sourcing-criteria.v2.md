## 왜 개정하나 — «위성공해» 실측

```
22비트 중 움직이는 화면 1  (b15)
켄번스 진폭 0.00~0.08       (b07 완전 정지)
4초+ 정지 홀드 6비트
B축 미달 20 / 22
```

v1 5단계는 정지 이미지를 먼저 찾고 영상을 4단계로 미뤘다. 실제로 스타링크 열차 **영상**이 후보에 올라왔는데 "영상이라서(webm 98MB)" 기각됐고, ESO 타임랩스 2편은 정지 스틸에 밀렸다. 결과가 영상 1 / 정지 21이다.

b01 훅은 검색어를 **문장이 아니라 기존 화면에서** 뽑아 실패했다 — "스타링크"라는 제품 명사가 있는데 밤하늘 궤적 쿼리만 6개 던졌다.

## 개정 7항

| # | v1 | v2 |
|---|---|---|
| 1 | 비트별 키워드(자유) | **검색어는 문장의 명사(주어·목적어)에서.** 기존 화면·기존 자산의 프레이밍에서 뽑지 않는다 |

| 3 | 기각 사유 자유 기술 | **기각 사유는 A·B·라이선스 중 하나.** "영상이라서"·"용량 커서"는 사유가 아니다 |
| 4 | 실물 확인(가로 원본) | **9:16 크롭 컨택트시트로 확인.** `ffmpeg -i <src> -vf "fps=<n>,crop=ih*9/16:ih,scale=340:604,tile=5x1" -frames:v 1 sheet.jpg`. 어두운 소재는 `eq=brightness=0.07:contrast=1.8` 리프트 후 판정 |

## 판정 2축 (수집 시점에 적용)

- **A 내용**: A1 주어·목적어 화면 안 / A2 배경지식 없이 알아봄 / A3 오인 없음
- **B 표현**: B1 피사체가 움직임(켄번스≠움직임) / B2 문장의 동사를 화면이 수행 / B3 정지 4초 초과 금지

훅(1~2초)은 A2가 결정적 — 즉시 읽혀야 한다. 4초 이상 비트는 B3가 결정적 — 영상이거나 인셋 등장 같은 화면 내 변화가 있어야 한다.

## 이번 회수에서 확정된 소재 지식

- **아마추어 스타링크 열차 영상은 확대해도 가는 점선.** 오렌부르크(CC BY 4.0)·아르헨티나(CC0) 실측. 훅에는 못 쓰고, "지우고 있습니다" 같은 진행형 4초 비트에서만 읽힌다
- **스타링크 제품 실물은 커먼즈에 없다.** 제품 8쿼리 → 영상 0, 이미지 77(발사·궤적·노이즈). 궤도 전개는 SpaceX 웹캐스트 = 저작물. 유일한 무료 경로는 SpaceX Flickr CC0(2019)
- **NASA SVS는 영상 창고다.** 5258(궤도 물체 추적, 활성/전체/스타링크 변형 17개 mp4), 4857(베누 회전 120s). 8/28 503이던 4857이 200으로 복구
- **facts B "색 범례 없이는 정지 유지"는 범례를 달면 해제.** b07/b08 완전 정지는 팩트 제약이었고 `label_overlay`로 조건 충족 → 팬 획득
