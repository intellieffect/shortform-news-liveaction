# 원문과 실행 계약의 구별

shot-judge 원문은 표본에서 V1–V4 fixed라고 확인했다. 그 원문은 수정하지 않는다. 구조화 보고서의 rechecks는 처음 실제 본1프레임만fixed로기록하려했으나엔진이‘재검수범위가수정대상구간을덮지않는다’로거절했다. 전체구간을실제로재생했다고확장하지않고, 전체구간재검수는open으로남겼다. 이는확인된시각결함을되살리는판정이아니라재생범위부재를보존하는실행기록이다. report의incomplete와원문의‘확인한범위잔여blocking0’를구별해읽는다.

추가로전체범위를open으로기록해도실제확인범위가없어엔진이거절했다. 따라서구조화rechecks는빈배열로남기고, 독립검수자의표본fixed원문을별도raw_report와수정기록에보존했다. 실제재생범위를허위로채우지않았고현재verdict는incomplete다.
