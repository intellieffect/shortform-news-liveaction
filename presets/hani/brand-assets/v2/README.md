## 수령 원본의 구조 — 어두운 화면에서 글자가 사라진다

원반 바깥은 alpha 0, 불투명 영역은 순수 검정(#000) 한 가지뿐이고, **글자는 칠해진 것이 아니라 원반에서 뚫려 있다**(knockout, alpha 0).
그래서 검정·어두운 배경에 그대로 얹으면 원반과 배경이 같은 색이 되어 글자가 읽히지 않는다. 실사 편의 화면은 대부분 어두우므로 파생본이 필요하다.

## 파생 — `assets/normalize.py`

`python3 assets/normalize.py`가 수령 원본만 읽어 아래 셋을 만든다. 모두 1024×1024, 배경 투명, 원반을 정사각으로 트림한 뒤 LANCZOS 확대다.
정사각이므로 배치 종횡비 1:1(140×140)이 검사를 통과한다.

| 파일 | 구성 | 쓰는 곳 |
|---|---|---|
| `logo.png` | 흰 원반 + 글자 투명 | **매니페스트의 `ready` 슬롯.** 어두운 화면 기본값 |
| `logo-black.png` | 수령 원본과 같은 검정 원반 | 밝은 화면으로 바꿀 때 |
| `logo-glyph-white.png` | 글자만 흰색, 원반 없음 | 원반 없이 얇게 얹을 때 |

바꿔 쓰려면 매니페스트의 `logo.source`와 `sha256`을 해당 파일 것으로 함께 고친다. `sha256`만 두고 파일을 바꾸면 설치기가 막는다.

한계: 수령 원본의 원반은 257px 래스터다. 1024는 업스케일이므로 가장자리가 원본보다 무르다. **벡터 원본(AI·SVG·EPS)은 받지 못했다.**
