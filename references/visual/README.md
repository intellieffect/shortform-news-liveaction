# 모든 제작에서 참고하는 표현 레퍼런스

이 라이브러리는 에이전트의 표현 선택과 결과 수준을 넓히는 공통 제작 입력이다. 새 영상의 연출 설계 전에 지정 공통 세트의 실제 영상을 모두 확인한다. 기사 주제나 표현 종류가 다르다는 이유로 열람을 생략하지 않는다. 현재 기준 세트와 파일은 collection.json이 정본이다.

## 확인과 판단

실제 MP4와 walkthrough의 시점을 연결해서 배경과 정보의 관계, 시선 유도, 미술, 발화와 움직임, 충분한 관찰 시간과 퇴장을 본다. 영상 인식 수단이 없으면 가능한 프레임 표본·타임코드·코드를 확인하고 그 범위를 기존 direction.md/decisions.md에 기록한다. 파일 전달과 열람 완료는 다르며, 표본 확인을 연속 시청으로 쓰지 않는다. 같은 세션에서 변경 없는 자료를 매번 재생할 필요는 없다.

내용과 자료에서 각 컷의 역할을 정하고 실사·사진·문서·지도·인용·비교·그래프·일러스트·도해 등을 판단한다. 공통 자막은 유지하고 색·선·재료·구도·등장 효과는 내용에 맞게 선택한다. 실사만으로 충분한 구간도 가능하다. 어려운 핵심 구간은 익숙한 첫 표현 외의 접근도 검토하되 컷마다 의무 후보 수·인용 기록·효과 수를 채우지 않는다. 생성 재료가 필요하면 기존 Higgsfield 지침에 따라 확보한다.

레퍼런스의 설명력·정보 위계·시선 유도·미술·합성·발화와 움직임의 완성도는 이번 장면에서도 충족한다. 사례의 구도·색·도형·배치·등장 순서를 가져올 때는 이번 대상·자료·관계를 명확하게 전달하는지 판단한다. 익숙하거나 승인된 형태라는 이유만으로 선택을 고정하지 않는다. 사실·대상·관계가 바뀌면 표현과 적용 판단도 다시 확인한다. 적합한 같은 기법을 사용할 수 있으며 외형의 차이 자체를 목표로 삼지 않는다. 핵심 정보와 필요한 조건·출처를 보존하면서 명확하게 전달하는 것이 기준이다.

## 실제 사례와 전체 영상

규모 비교는 공통 기준과 정보 위계, 관측 확대는 시선 유도와 전체 맥락, 산란은 원인-작용-결과와 실사 합성의 사례다. 개별 기법의 적용 조건이 사례 열람 조건은 아니다. 짧은 사례 장면만으로 한 편의 도입·전개·결말·음향을 검증할 수 없으므로 기존 전체 시청 경험 검수를 유지한다.

검수는 이번 영상 자체의 관찰을 먼저 받고, 의도 대조 단계에서 같은 기준 세트와 비교한다. 유사도나 사용 기법 수로 평가하지 않는다. 새로운 좋은 표현은 사용자 확정 후 후보로 추가한다. 사례 수 자체를 채우기 위해 만들지 않는다.

## 납품과 재현

Git LFS 미디어를 받은 뒤 npm ci. npm run videos:serve로 표현 레퍼런스 탭을 연다. 각 사례 source/README.md에 수정·재렌더 명령이 있다. 자료 출처는 사례별 credits.md를 함께 전달한다. 확정 영상은 불변이고 개선본은 새 버전으로 추가한다. 생성 캐시는 public/references, 시험 출력은 out/references에 복원하며 공유에 포함하지 않는다.
