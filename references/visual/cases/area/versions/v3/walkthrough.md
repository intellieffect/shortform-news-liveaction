# 면적비를 같은 하늘 위에서 읽히기

로먼과 허블의 상대 관측 면적을 1 대 약 100으로 이해한다.

- 0.63초: 같은 배율의 하늘 위에서 허블 기준 영역을 읽는다.
- 2.00초: 1 발화에 기준값이 나타난다.
- 3.10초: 고정 기준 영역에서 큰 영역이 확장된다.
- 4.10초: 약 100배 수치와 최종 면적을 함께 본다.

## 다른 기사에 적용할 판단

- 선형 길이와 면적의 비를 구분해 실제 도형 비율로 전달한다.
- 수치와 해당 영역을 발화에 맞춰 직접 연결한다.

## 사례 고유 선택과 한계

- 생성 은하 배경은 실제 관측 자료가 아니다.
- 로먼 WFI 대 HST/ACS의 상대 면적 약 100배를 설명하며 실제 검출기 형상·절대 각면적을 재현하지 않는다.
