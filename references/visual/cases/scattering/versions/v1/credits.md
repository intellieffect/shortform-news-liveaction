반사·산란은 imagegen 시작/끝 시안을 Higgsfield Kling3.0으로 영상화한 도해. 1080p/5초/음성off. 원본과 실제 시작/끝 입력 및 생성 프롬프트 수록. 후반은 같은 실제 ESO 하늘 프레임에 밝기를 가산한 대비 예시이며 실제 전후 관측 비교가 아니다.

내레이션: Higgsfield MiniMax Speech2.8HD, 기존 프로젝트 음성. 생성된 확정 WAV 재사용. 출처는 이 문서와 재생 화면에서 제공하며 영상에 출처 텍스트를 추가하지 않았다.
