# 보이지 않는 작용을 결과까지 연결하기

반사빛의 대기 산란과 희미한 별의 대비 저하를 연결한다.

## 다른 기사에도 적용할 판단

- 같은 대상의 작용과 결과를 끊김 없이 설명한다.
- 생성 재료와 실제 배경을 하나의 화면으로 합성한다.
- 발화에 맞춰 변화를 전개하고 변화 전후의 기준을 유지한다.

## 실제 영상 관찰

- 0.9초: 입사광을 오른쪽에서 위성 쪽으로 드러낸다.
- 2.5초: 연결된 반사 경로가 대기로 이어진다.
- 4.6초: 대기의 여러 지점에서 빛이 퍼지는 상태를 보여준다.
- 6.5초: 같은 하늘에서 배경이 밝아지며 별의 대비가 낮아진다.

## 이 장면의 선택과 범위

- 금빛 리본·청색 대기·위성 형태는 이 장면의 개별 미술 선택이다.
- 생성 도해이며 정량 광학 시뮬레이션이 아니다. 후반은 같은 하늘 프레임에 배경 밝기를 더한 예시다.
