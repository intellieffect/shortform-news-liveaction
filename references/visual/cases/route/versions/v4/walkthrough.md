# 경로와 목적지를 한 장면에서 연결하기

지구 저궤도 비행 뒤 태평양으로 돌아오는 계획의 공간 관계를 설명한다.

- 0.64초: 계획임을 나레이션으로 밝힌다.
- 1.56초: 궤도와 이동점을 따라간다.
- 4.25초: 태평양 발화에서 해당 해역을 본다.
- 6.35초: 귀환 표시와 주변 지형을 관찰한다.

## 다른 기사에 적용할 판단

- 이동 대상·경로·목적지의 관계를 발화와 연결한다.
- 장면 내부 카메라 이동으로 공간 맥락을 드러내며 화면 가장자리를 채운다.

## 사례 고유 선택과 한계

- 통합 생성된 계획 개념도이며 정확한 1.5회 궤도와 실측 좌표는 검증되지 않았다.
- 영상 평면을 확대·축소하지 않으며 생성 원본 내부 카메라 동작을 사용한다.
