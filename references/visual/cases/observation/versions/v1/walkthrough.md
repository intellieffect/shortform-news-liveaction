# 작은 대상을 전체 맥락 속에서 보여주기

관측 사진에서 동반별 후보의 위치와 모습을 찾게 한다.

## 다른 기사에도 적용할 판단

- 시선을 유도하면서 원래 위치와 전체 맥락을 유지한다.
- 실제 자료의 해상도·표식을 보존하며 보여줄 영역을 설계한다.
- 등장·확대·관찰·퇴장을 하나의 장면 흐름으로 만든다.

## 실제 영상 관찰

- 0.2초: 관측 사진이 실제 천문대 배경 위에 등장한다.
- 1.7초: 왼쪽 아래로 확대하면서 전체 위치창을 함께 제공한다.
- 4.6초: 십자선과 작은 광점을 읽을 시간을 유지한다.
- 9.4초: 사진과 위치창이 함께 퇴장하고 배경으로 돌아간다.

## 이 장면의 선택과 범위

- 연속 확대와 전체 위치창은 이 사진에 맞춘 선택이며 모든 사진의 고정 양식이 아니다.
- 베텔게우스 동반별 후보다. 광점 선명화나 생성 보강을 하지 않는다.
