# 출처와 사실 범위

배경: NASA Scientific Visualization Studio / Global Science and Technology, Inc. / Marit Jentoft-Nilsen. https://svs.gsfc.nasa.gov/31375/
기존 프로젝트의 Public domain/cleared 기록에 따라 사용. 새 권리 재조회는 하지 않았다. 원본 76–82초 구간의 속도·크롭·명암 변경. 오로라/대기광은 위성 공해의 관측 증거가 아니다.

보관 한겨레 위성공해 기사에 따른 당시 신청·계획: SpaceX 100만, E-Space 30만, 중국 여러 계획 합계20만, Reflect Orbital 2035목표5만 기. 독립 1차 출처 재대조 미실시.

내레이션: Higgsfield MiniMax Speech2.8HD, 기존 프로젝트 음성. 생성된 확정 WAV 재사용. 출처는 이 문서와 재생 화면에서 제공하며 영상에 출처 텍스트를 추가하지 않았다.
