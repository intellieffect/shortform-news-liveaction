# 수량 차이를 같은 기준으로 읽히기

주요 위성 신청·계획의 수량 차이를 한눈에 비교한다.

## 다른 기사에도 적용할 판단

- 정보를 같은 기준에 놓아 차이를 형태로 읽히게 한다.
- 발화에 맞춰 정보를 공개하고 비교할 시간을 남긴다.
- 배경의 맥락과 그래픽의 읽힘을 함께 설계한다.

## 실제 영상 관찰

- 0초: 실제 지구 영상 위에 비교 기준을 세운다.
- 3.6초: 첫 막대가 공통 영점에서 펼쳐진다. 수치는 카운터로 흔들지 않는다.
- 12.1초: 마지막 작은 값도 같은 척도로 표현한다.
- 14.6초: 전체 항목을 비교할 시간을 유지한다.

## 이 장면의 선택과 범위

- 막대그래프와 공통 영점은 이 사례의 선택이다. 비교표·면적·대상 이미지로도 재설계할 수 있다.
- 신청·계획 수치이며 현재 운용 수량이나 시간 추이가 아니다. 네 항목은 전체의 일부다.
