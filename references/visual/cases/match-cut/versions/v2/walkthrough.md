# 익숙한 움직임에서 실제 관측으로 연결하기

커피 속 흐름을 비유로 태양 표면의 소용돌이 관측에 진입한다.

- 0.58초: 커피에 섞이는 크림을 본다.
- 1.87초: 태양 발화에 실제 관측 영상으로 하드 컷한다.
- 5.10초: 발화가 끝난 뒤에도 관측 움직임을 본다.

## 다른 기사에 적용할 판단

- 친숙한 비유에서 실제 증거로 전환하는 시점을 발화에 맞춘다.
- 유사한 움직임을 연결하되 실제 관측과 비유의 역할을 구별한다.

## 사례 고유 선택과 한계

- 커피와 태양은 같은 물리 현상의 증명으로 제시하지 않는다.
- 태양은 착색된 실제 관측 영상이며 생성·모핑하지 않았다. 원본 클립 재생속도 1배이고 실제 현상의 시간 축척은 주장하지 않는다.
