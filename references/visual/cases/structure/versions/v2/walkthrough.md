# 부분 연결에서 전체 구조로 보기

탄소 원자 60개가 이루는 속이 빈 C60 구조를 이해한다.

- 0.64초: 근접 화면에서 원자와 결합을 본다.
- 3.20초: 속이 빈 공 발화에 전체 구조가 보인다.
- 5.50초: 작은 시점 이동을 마치고 형태를 관찰한다.

## 다른 기사에 적용할 판단

- 부분의 연결을 먼저 읽고 전체 형태로 시야를 넓힌다.
- 구조를 말하는 순간 전체 형상을 보여주고 작은 시점 이동으로 입체성을 전달한다.

## 사례 고유 선택과 한계

- 60개 꼭짓점·90개 결합·각 꼭짓점 차수 3의 잘린 정이십면체 모형이다.
- 원자 크기·결합 굵기는 연결 설명용이며 실측 원자 크기가 아니다.
