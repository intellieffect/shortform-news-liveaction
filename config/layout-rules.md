# 공통 배치와 자료 출처

2026-09-29 사용자 승인 기준. 새 편은 공통 설정과 `screen-text@2`를 사용한다. 과거 원본·납품본·편별 brief는 덮어쓰지 않고 승인된 기존3편만 제작 파생물을 명시적으로 전환한다.

## 수치 (1080×1920, 30fps)

| 영상·후킹 중심 | x540, 영상은 전체 캔버스 사용 | 편별 구도 |

끝 크레딧 수치는 초기 구현값이며 내용량에 맞춰 페이지를 나누고 실제 모바일 가독성을 검수한다. 글자를 임의로 줄이거나 출처를 생략하지 않는다. 배경판 없음은 화면 자료 출처에 적용하며 끝 크레딧은 검은 배경이다.

## UI 판정

Google 광고 safe-zone은 참고다. 모든 요소를 작은 공통 사각형 안에 모으거나 영상 중심을 옮기지 않는다. 상단 검색·더보기, 우측 액션, 하단 채널·설명·링크와 해당 높이의 글자/박스가 겹쳐 정보가 가려지는지 확인한다. 첨부 iPhone16/Pixel7 에뮬레이터의 관찰 좌표와 실제 영상→앱 좌표 변환 확정은 구별한다. 원해상·모바일 크기의 정지 화면과 앱 재생을 확인하며 미확인을 통과로 기록하지 않는다.

## 한 줄 자막

문장 쉼표가 나오면 그 뒤 내용은 다음 시점의 자막이다. 두 줄 동시 표시가 아니다. `1,000`의 내부 쉼표는 분할하지 않는다. 폭이 넘으면 실제 발화 시각에 맞춰 더 작은 구절로 분절한다. 글자 크기는 줄이지 않는다. 실제 폰트 폭 검사를 유지한다.

- 폭: 조립 단계가 `public/fonts`의 GmarketSans Medium·Bold TTF를 opentype.js로 읽어 실제 글자 폭을 잰다(강조 가능성 때문에 둘 중 넓은 값). 브라우저·네트워크를 쓰지 않는다. 렌더 폭 검사와 정지 화면·청취 검수는 여전히 필요하다.
- 가로 폭780/756은 프로필 1.4.0의 잠정값이다. 실제 모바일 화면 확인(6단계) 전에는 확정값이 아니며, 공통 safe-area 기준도 아니다. 1.3.0(폭672/글자648)과 그 이전 프로필은 `config/production-profiles/`에 보관되어 해당 편은 기존 배치와 추정식 분절을 유지한다. 새 프로필의 `caption.segmentation:font-semantic@1`에서만 실측·의미 분절을 적용한다.
- 분절: 쉼표·문장부호·0.8초 넘는 쉼에서 먼저 끊고, 그 안에서는 폭에 맞는 모든 끊기를 비교해 자막 수가 가장 적은 것 → 어절 경계 품질 → 줄 폭 균형 순으로 고른다. 글자 수 제한은 두지 않는다.
- 경계 품질은 앞 어절 끝의 표면형 규칙이다. 조사·연결어미 뒤는 자연스러운 경계, 관형형(ㄴ/ㄹ 받침)·속격 `의` 뒤는 감점, 조사 없는 명사 뒤(복합명사 추정)는 더 큰 감점, `것·수·때` 같은 의존명사가 줄머리에 홀로 오는 끊기는 큰 감점이다. `는`은 주제 조사/관형형이 모호하므로 연속성 감점을 주어 우선 경계로 삼지 않는다. 형태소 분석이 아니므로 `은`의 조사/관형형 구분 등에는 오판이 있다. 폭 안의 후보가 모두 나쁘면 감점이 가장 적은 끊기를 쓴다. 결과는 정지 화면 검수로 확인한다.
- 한 어절이 한 줄 폭보다 길면 조립이 실패한다. 줄이지 않고 원고를 고친다.

## 공용 출처 입력

`visual-system.json.attribution.sources`에 `{asset_id,text,start,end}`를 작성한다. 초 단위 노출 구간은 실제 자료가 화면에 보이는 구간과 일치시킨다. 여러 자료를 동시에 표기할 때는 `asset_id` 대신 `asset_ids` 배열로 모두 연결한다. 출처는 원자료 지정 표기를 사용하며 같은 위치의 동시 출처는 한 문구로 합친다. 원본 자료의 출처를 임의 축약하지 않는다.

`attribution.pages`는 `{duration,categories:[{title,lines:[]}]}` 목록이다. 본편 뒤에 순서대로 붙으며 카테고리마다 새 줄을 쓴다. 새 편은 참조 기사 URL이 있는 초기 페이지를 받는다. 이는 완성 크레딧이 아니며 제작자가 실사용 이미지·영상·데이터·생성·시작이미지·음악의 해당 항목을 대조해 채운다. CREDITS.md와 게시 설명도 유지한다. 길면 페이지를 늘리고 내용에 맞게 노출 시간을 정한다. 장식용 아웃트로 추가와 구분한다.

검사: 출처 자산 연결·시간 범위·동시 겹침·페이지 형식과 표시 넘침을 검사한다. 출처의 정확성·누락과 노출 구간의 실제 화면 일치는 제작·시청 검수 대상이다. 공용 출처를 편별 코드에 중복 합성하지 않는다.

## 분량 기준

`produce start --duration-basis content`는 본문 길이를 검사하고 끝 크레딧을 별도로 더한다. 사용자가 본문 분량을 지정했을 때 사용한다. 기본값 `total`과 기준 미기록 과거 편은 크레딧 포함 전체 길이를 검사한다. 실제 렌더의 전체 프레임·음향 길이 검사는 두 경우 모두 유지한다.
