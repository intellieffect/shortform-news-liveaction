# 이 프로젝트의 제작 기본값

새 기사 제작은 먼저 [실제 V2 제작 프롬프트](../docs/PRODUCTION_PROMPT_V2_RESTORED.txt) 전문을 읽고 적용한다. URL과 짧은 제작 요청만으로 시작하며 사용자에게 긴 프롬프트 입력을 요구하지 않는다. 원문·URL 치환본 보존과 재개 규칙은 [루트 진입 지침](../CLAUDE.md#기사-url과-짧은-제작-요청의-첫-진입)을 따른다. 이 문서는 그 프롬프트에 적용할 프로젝트 설정이다.

우주거울 완성본의 엔진 커밋59a2af7을 기반으로 복원한 editorial-concept 제작이다. 기사·자료에 맞춰 원고, 개념, 발화 앵커, 편별 장면을 설계하는 기존 흐름을 쓴다. 종이 스타일과 V5는 이 복원본의 기본값이 아니다.

- 일반 비전공 시청자, 한국어60~90초를 출발점으로 삼고 이번 사용자 조건을 우선한다.
- 실제 자료를 근거로 삼고, 과정·관계·규모·정의·인용은 정보에 맞는 영상·이미지·도해·정보그래픽으로 표현한다. 장면 수·실사 비율·고정 서사 순서를 강제하지 않는다.
- 생성 영상·오버레이 이미지·모션그래픽의 외형과 동작은 Higgsfield를 활용한다. 생성 사용과 종이 미술 선택은 별개다. 정확한 수치·문구·배치·발화 타이밍은 코드로 제어하고, 현상의 작용 전체를 생성해 합성할 수 있다. 제공자 지침은 플러그인 generation-provider.md를 읽는다.
- 내레이션 보이스는 계정마다 다르다. 제작자가 고른 값을 `TYPECAST_VOICE_ID`(필요하면 `TYPECAST_VOICE_NAME`)로 주거나 이 폴더의 `production-defaults.json`에 `narration.voice`로 적는다. 키는 `.env`의 `TYPECAST_API_KEY`다(`.env.example` 참고). 기본값으로 특정 보이스를 가정하지 않는다 — 수록 N44 편의 값은 그 편의 기록일 뿐이다.
- 공통 자막은 config/production-profile.json을 사용한다. 현재 GmarketSans70px·한 줄·고정94px바이며 새 편은 start에서 연결한다. 정보그래픽 본문은 한 줄 자막 규칙으로 제한하지 않는다.
- 화면에 상상도·AI 재구성·개념도·관측 아님·출처·라이선스 표기와 나레이션을 다시 적는 설명 문구를 넣지 않는다(`screen-text@1`, 2026-09-23 사용자 지시). 출처·생성 고지는 CREDITS.md와 게시 설명란, 예측·조건은 나레이션 문장과 화면 형태로 전달한다. 세부는 [화면 글자](../plugin/skills/shortform-news-pipeline/reference/visual-production.md#화면-글자).
- 화면 글자는 도형·대상에 붙은 키워드 하나로 쓰고 의미는 형태와 움직임으로 전달한다. 수치·연도·이름은 눈금·기준 도형·비교 대상·지시선 같은 기준에 붙이고, 기준을 세울 수 없으면 나레이션에 맡긴다([키워드는 기준에 붙인다](../plugin/skills/shortform-news-pipeline/reference/visual-production.md#키워드는-기준에-붙인다)).
- 수령 로고는 start가 편별로 복사·연결하고 공통 화면에서 합성한다. 로고를 새로 생성하거나 장면 코드에 중복 삽입하지 않는다. 인트로·아웃트로는 추가하지 않는다.
- 첫 전체 시안→독립 실물 검수→수정→재검수를 수행한다. 핵심 설명의 실패는 글자나 작은 장식 추가로만 덮지 않는다. 실제 시청/청취 미확인은 그대로 남긴다.

수록된 N44 완성본은 docs/CUSTOMER-EXAMPLE.md에서 연다. 미술 완성도·정보별 장면 선택의 참고이며 원고·구성·좌표를 복제하지 않는다. 예시의 미완료 검수 범위는 그대로 유지한다. 고객 전달본에는 다른 과거 편의 영상이 포함되지 않는다.

start는 이 문서를00_brief/production-defaults.md에 보존하고 resume은 그 편의 사본을 연결한다. 기존 편에는 새 기본값을 소급 적용하지 않는다. 사용자 조건이 기본값과 다르면 제작 노트에 선택과 이유를 남긴다.

새 제작의 설명 설계·초기 시안·생성 기록·화면 문구는 [발화→화면 제작 계약](../plugin/skills/shortform-news-pipeline/reference/visual-production.md)을 적용한다. 구조 검사 통과와 새 세션의 실제 영상 품질 검증은 구분한다.

새 편의 기본값은 `first-core-scene@5`다. 첫 핵심 장면 시험은 선택이며 음성 착수 게이트가 아니다. 원고·주요 자료·표현 수단이 정해지면 음성과 전체 시안으로 진행하고, 그 선택을 바꿀 구체적 불확실성이 있을 때만 시험한다. 외형·합성 가능성은 제작자가 직접 확인하고, 독립적인 의미나 오독 관찰이 필요할 때만 `scene-judge`를 부른다. 시험 질문·진행 판단·실패 시 대안은 기존 제작 노트에 짧게 남기며 별도 기획 서식을 만들지 않는다. 이전 `@1`~`@4` 편에는 소급 적용하지 않는다.
